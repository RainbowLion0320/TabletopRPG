# 0.4.3 调查员档案验收（2026-09-09）

行动区头像和队员卡原先没有交互，已有玩家详情仅展示背景及 HP/SAN。现在三个入口（头像、队员卡、正文玩家姓名）统一打开调查员档案。

## 行为与布局

- 属性页读取当前 HP/MP/SAN/幸运和八项基础属性；技能页可搜索并显示普通、困难、极难检定阈值，复用实际规则函数，职业技能单独标记；随身与背景页仅显示角色明确记录的信息。
- 查看对象以 ID 存储，数值从当前队伍实时读取。查看队友、切换页签、关闭面板都不修改行动角色、资源、声明或草稿，也不会触发 AI 请求。
- 黄铜档案边框、小幅立绘、身份及关闭按钮；多人姓名按钮、分类页签与技能搜索位于滚动区外。正文独立滚动，技能列名保留在列表顶部。支持键盘页签、Escape、系统返回及焦点恢复。
- 头像点击范围 44×44px，队员卡至少 40px 高。320×568 四人模式的场景行允许缩小，优先保证剧情面板至少 140px 和底部操作不越界；完整图片等比例容纳。键盘剩余 300px 时档案收起肖像及队员选择，保留姓名、页签、搜索和关闭。
