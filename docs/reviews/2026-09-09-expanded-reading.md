# 0.4.2 展开阅读修复验收（2026-09-09）

用户反馈展开故事后，顶部章节/地点栏被面板盖住，NPC 信息条悬在已滚动的剧情上。原布局让展开面板跨过导航行，并让标题与正文共用滚动容器。

展开区域现限定在导航与行动区之间：竖屏跨场景及剧情两行，桌面从 64px 顶栏下方开始。面板改为固定标题加独立正文滚动区，NPC 名牌与收起按钮不随正文移动。自动定位最新消息按正文容器计算偏移，收起后恢复场景；按钮提供展开状态与可访问名称。

- `npm run check:full` 通过：41 个文件 / 530 项单元测试、网页生产构建及 63 项流程测试。日志 `output/reading-check-full.log`。
