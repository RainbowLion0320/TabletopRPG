# 0.4.4 竖屏单列选角验收

## 问题与结果

用户反馈同事手机的选角页出现两列，卡片资料被压窄、属性标签换行。原因是 `portrait.css` 在 600 CSS px 起把选角列表覆盖为两列；手机上报的逻辑宽度达到该断点就会触发，与截图文件的像素尺寸不直接等同。

所有启用竖屏布局的设备现在固定一行一名调查员，取消这一双列覆盖。卡片保留左侧立绘、右侧资料；顶栏、列表与底栏居中对齐，最大宽度 720px。列表独立纵向滚动，人数和进入按钮留在底部。默认单人，属性展开保留选择；支持显式加选双人及四人。

改动位于 `codex/android-apk`，APK 与该分支窄网页共用修复。原网页目录 `G:/TabletopRPG` 的 main 工作区保持干净。游戏规则、AI 请求和存档格式不变。
