# Android 0.3.1 场景画幅修复

用户反馈竖屏中只能看到横向场景的一小部分。0.3.0 的背景仍填满整个竖屏容器，`object-fit:cover` 因宽高比差异裁掉大部分两侧环境。当前场景原图均为 1896×1080。

修复仅调整 Android 样式：背景移到导航下方独立网格行，按原图比例铺满手机宽度，画幅底边不超过上半屏；图片等比例完整容纳，宽窗口受高度上限约束时也不裁图。NPC 位于画幅内，剧情和操作位于其下。无 NPC 时保留场景，展开阅读或可用高度不超过 500px 时收回画幅。原网页目录 `G:\TabletopRPG` 与 `main` 保持 `118cf49`，玩法、AI 配置与存档格式不变。
