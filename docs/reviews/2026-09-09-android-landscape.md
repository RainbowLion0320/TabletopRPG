# Android 0.2.1 手机横屏审查（2026-09-09）

用户实玩反馈旧版控件偏大、内容越界。本轮仅在 `codex/android-apk` / `G:/TabletopRPG-android` 修改；原网页目录及 main 保持不变。

## 问题与处理

- 首页视频改为块级显示并裁切背景溢出，消除短屏中无内容需要滚动却出现的整页滚动条。
- 旧 API 表单在 740×320 视口中内容高度接近 600px，保存按钮随整个弹窗滚出屏幕。改为横屏两行表单，表单内容单独滚动，取消/保存保留在外侧；输入法占位后聚焦字段仍可滚入可见区域。
- 选角继承桌面卡片的列最小宽度、字号与间距，短屏只能看到部分角色信息。改为单列内容配窄立绘、两张卡并排、顶部操作栏常驻；完整属性在卡片内部展开，取消向屏幕外展开的绝对定位浮层。
- 正文、输入区和桌面控件争抢高度。重新分配顶部/正文/行动区，统一手机字号和间距；检定/重试时收起无法编辑的输入行；资料改为顶部图标、菜单双列；三/四人队伍所有成员状态并排显示。
- 声音设置改为音乐/音效并列；实体详情改为立绘/资料并列。存档、KP 笔记和长说明只滚动内容，关闭控件保留。骰子沿用美术比例与侧排说明/确认。
- 资料页固定浅层标题栏，列表/关系图使用剩余高度；窄屏资料卡两列，宽屏关系图保留。移动资料详情接入对话框焦点栈，系统返回先关详情、保留案件板。
- 所有手机覆盖规则以 `html.android-app` 为作用域，覆盖动态导入的共享组件样式及 portal，避免加载顺序重新引入桌面尺寸。使用 CSS 视口、安全区和 flex/grid 收缩，不使用页面 zoom。
