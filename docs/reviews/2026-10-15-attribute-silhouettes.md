# 0.5.76 属性剪影验收

为选角和局内调查员档案的十二项属性补齐统一的单色剪影底纹。沿用美术现有银蓝数值框，低对比银灰底印辅助辨认含义，名称、缩写和实际数值保持在前景。

| 生命 / 魔力 / 理智 / 幸运 | 心脏 / 灵焰 / 人物侧影 / 四叶草 |

`AttributeEmblem` 共用十二种96单位矢量，以单色填充和留白刻纹保持小尺寸识别；背景透明度14%，按原数值格缩放且裁剪在格内。装饰不占页面高度，不拦截触摸、不进入键盘顺序、不重复朗读属性；系统强制高对比时隐藏。没有增加按钮、说明弹窗、玩家步骤或模型调用。
