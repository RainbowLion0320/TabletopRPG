# 《雾中消逝》交互 UI 规范

当前视觉规范为 0.5.27，沿用 0.5.0 的美术原稿、0.5.2 的精绘框架和自动保存优化。专用图像覆盖骰子、阅读/档案、立绘、输入、工具图标、标题和声音推子；制作与验收见本页末尾重构计划。用户于 2026-10-09 指定 `D:\首图素材（这版为准）` 为视觉事实源，取代此前黄铜/皮革方案。APK 手机竖屏优先，网页使用同一套美术语言；旧版本记录保留在 [历史验收](reviews/2026-10-08-ui-polish.md)，不作为新控件的视觉参考。

## 美术与首页

- 首页直接使用美术成稿的标题、金色「新游戏」、浅蓝「继续游戏 / 设置」切图，以及伦敦雨雾背景。原图嵌在真实按钮中，保留语义名称、键盘操作和原处理函数。
- 桌面按 2048×1136 构图缩放：首按钮为 (796,470) 的 498×127 图，后两枚位于 y638/807；标题保留成稿原形和渐变。手机单列居中，正常窗口不依赖滚动才能进入游戏；声音为右上角 44px 图标。
- 导航按原稿保持新游戏、继续、设置三项顺序。有当前调查时焦点仍到继续游戏，一次点击恢复同一草稿与行动人；已结案使用实时「回顾调查」，不再次请求 AI 或结算。设置沿用 AI 配置，声音入口独立。
- 原动态背景静音循环，未开始或不可播放时保留静态封面，后台和减少动态时暂停。图片和视频不接管输入。
- 无字按钮从原 PSD 只读导出，缺失的阅读面板和方形图标底板参考原稿补齐。来源、切片与转换见 [原稿资源](../assets/ui/artist/README.md)。原始设计稿不提交。

## 控件、文字与状态

0.5.27 长局输入复用未变化的剧情富文本，完整历史和原阅读位置保留。每次界面更新仍读取全部已知资料和人物颜色，正文/提示/类型/知识改变会重新绘制；点击资料使用最新已提交状态，不显示过期信息。手机多行行动、单人/多人换人、草稿、模型调用与存储链路保持；十七张银蓝精绘图、声音控制、中文核心数值与固定面板布局保持。

从 0.5.3 起，共用弹窗对输入法组字事件（`isComposing` 或旧式键码 229）不执行 Escape 关闭或 Tab 焦点循环，避免候选操作丢掉未保存输入。普通按键仍由最上层弹窗处理，关闭返回实际入口；没有增加确认步骤或提示。

按钮按下轻微下沉和亮度变化，悬停适度变亮，焦点使用象牙白内框。禁用既保留可读文字也保留原 disabled 语义；静音、选择和提交状态有明确文字，不能仅靠颜色识别。减少动态设置关闭额外过渡。装饰层统一 `pointer-events:none`。

控件/标题沿用字魂云雀宋，剧情、资料正文和配置值使用现有宋体/衬线栈，骰子弹窗所有文字均用字魂云雀宋。许可说明见 [字体说明](../assets/fonts/README.md)。正文 `#eef3fb`、辅助 `#b5c7e0`、深底 `#0d1725`、面板 `#18283c`、按钮深墨 `#23314a`，重点色 `#c4d9f1`；资源属性和错误保留低饱和功能色。

主故事正文 15px；行动建议 14px/44px，提交与下一位 15px/48px；设置字段和主要弹窗操作 15px，输入 16px。资料身份/关系 14px、已知正文/来源 15px；姓名和状态保持原已验证字号。通过间距与层级保持紧凑，不缩小关键文字来遮掩溢出。

阅读框 768×768 / 96px 九宫格，装饰只在固定角区，边中段为均匀细线；输入框使用 `90 100 90 100` 切片。立绘框中心透明，放在原人物上方，不替换人物或照片比例。标题分隔图只放入已有标题/底部留白，不扩大弹窗或遮挡关闭；音量 24px、开关 16px 珠光图使用 contain，真实命中仍为 44px。骰子底图按原面板比例缩放，外部透明；总点数、原骰子与结果分别叠在既定安全区，普通窗口数字随面板缩放，短窗口骰面字至少 14px、结果至少 13px。全部压缩素材、生成记录及完整提示词见 [资源说明](../assets/ui/artist/README.md)。

## 手机主循环

网页桌面资料入口以按钮自身高度参与百分比定位，窗口缩短后整块仍可达；拖动直接跟随指针且不打开资料。桌面高度不超过 600px 时场景先让出，400px 时收起建议并将长输入限制为 66px，300px 时队伍条让出空间但头像仍能查看全队。保持顶部导航、至少 60px 正文阅读和原字号；恢复大窗口重新显示场景与队伍，手机仍用原固定入口。

顶部任务、地点、故事时间和资料/菜单固定；上部场景按原 1896×1080 画幅完整 contain，NPC 同比例叠放。中部剧情、底部行动分配剩余空间；空间不足时场景先让出，正常 320×568 四人窗口仍保留至少 140px 剧情和全部队员入口。

故事展开只从顶栏下扩展至行动区上；NPC 名牌和收起按钮固定，只有正文滚动。回看时新回复保持原位置，「新内容」可主动从新回复起点阅读；内部诊断不徽标、不挪动历史。名牌与阅读工具至少 44px，长名字必要时省略，但完整名称可访问。

行动区使用按内容排布的有界多行输入。手机 Enter 换行，显式提交/下一位确认；桌面 Enter 提交、Shift+Enter 换行。手机空提示为「描述你的行动…」，角色身份在头像、队员卡和可访问名称中。原建议先去重再按既有限额展示，保留玩家归属，横滑且点入输入后手动确认，不增加 AI 限制。

输入手机最大 96px，300px 键盘窗口最大 66px，桌面最大 104px，更长描述在框内滚动。行动区上限由半屏和顶栏/最小故事/安全区共同限定，避免四人加长草稿裁掉底部卡片。500px 以下场景收起，300px 以下队伍/建议/顶栏让出空间；阅读与提交仍可达。手机网页输入为 16px，避免输入缩放。

队员卡至少 48px，姓名 14px、数值 13px、「生命／理智」标签 12px；小量条用既有银蓝精绘输入槽和低饱和功能色，原宽度不变，减少动态时立即更新。已提交只用文字标明，整个属性卡不淡化。手机多人双列，原生宽竖屏至少 760px 才四列。查看队友档案不切换行动人，关闭保留草稿、资源和原焦点。

## 选角、资料与弹窗

声音入口精绘徽记 20px，首页/选角纯图标入口 24px；音乐留声机、音效徽记与声音标题调节盘均 24px contain。所有装饰为空 alt、aria-hidden、无命中，原频道名、开关和百分比仍由真实控件显示；标题和关闭固定，频道/鸣谢独立滚动。

选角生命/魔力/理智/幸运标签用 13px 中文，原缩写仅作前三项悬停提示，格内数值、色标和原布局保持；局内同称魔力 MP。手机无需悬停也能辨认核心资源，不增加解释弹窗或选择步骤。

AI 设置与连接折叠控件共用 20px 银蓝调节盘，标题 24px；装饰为空 alt、aria-hidden、无命中，不替代控件名称。标题/底部操作固定，原配置字段独立滚动；短窗口关闭后原入口不可见则局内返回头像、结案返回调查回顾，普通窗口仍回原入口。

存档菜单保存用 20px 精绘档案夹，读取标题用 24px 亮色书册；装饰保持空 alt、aria-hidden 和无命中。非交互状态签牌复用银蓝输入槽、24px 高与 13px 文字，不新增步骤。存档/调查菜单关闭优先返回原入口；入口被短窗口隐藏时仅补回可见头像，不抢其他有效焦点，草稿和原操作保持；已结案且无行动头像时补回「调查回顾」。

技能和案件无匹配/无记录也共用既有精绘调查册和 15px 原状态，原阅读区域内居中且无额外滚动；空技能只显示提示，清空查询后恢复原表头与阈值。正常记录、搜索/分类/关闭、焦点和短窗口保持，无新增资源文件。

空日志、无匹配和空存档共用精绘银蓝调查册（112×72px，无命中/访问名称），状态文字 15px。空日志居中于原阅读区，空存档不扩大原区域；高度 ≤500px 时隐藏装饰，仅保留提示和可到达操作。实际采用图和完整生成/编辑记录见原稿资源说明。

选角完整属性使用可见中文主标签 13px、原缩写副标签 12px，与局内档案一致；手机无需悬停即可辨认。八项名称/数值仍放在原四列精绘格中，自然增高且独立滚动，折叠卡片与固定操作不增加占位。

选角职业与擅长技能 13px、简介 14px，四项核心中文标签 13px；核心及展开属性格采用既有精绘框的 3px 切片，四类数值保留独立色标。展开属性标签 13px、技能/背景 14px，底部人数 14px、模式 13px。320px 内仍完整换行，详情展开与选择分离，底部操作固定。

选角默认单人；竖屏始终一行一人，左立绘、右身份/简述/两项擅长技能/生命-魔力-理智-幸运。姓名、选择标记和源按钮共同说明选中；原生 checkbox 支持整张资料点击和空格。详情展开独立于选择，放在列表内，进入/已选人数/返回固定。网页宽屏双列，竖屏最大宽度 720px。

调查员档案随可用高度收紧：500px 以下共用精简身份与横向队员导航，360px 以下隐藏次要身份、缩小护边间距；桌面留 10px 外边距，手机仍遵守自己的安全区。关闭、分类和搜索保持固定，300px 高至少能完整读一行筛选结果，表头 13px；恢复正常高度显示原头像和身份，搜索、阅读位置和多行行动不变。

调查员档案保留属性、技能、随身与背景三个页签；手机核心资源两列，标签/上限 14px、当前值 22px，基础属性缩写 12px。队友、分类、关闭与清空至少 44px，技能搜索与表头固定，正文独立滚动。切页保存位置，换人/查询从开头，清空后继续输入；短窗口减小身份区，队友横滑但仍可切换。

案件地点缩略图使用 84×56px 横向装裱，既有阅读框作 3px 无填充护边，场景全幅居中 contain；手机列表、桌面关系图和失败后的档案共享，卡片原最小高度、字级与人物立绘保持。小手机的名称、说明和关联箭头不被缩略图挤出。

网页关系卡名称 17px、身份说明 14px、类型 13px、状态 12px，关系线文字 13px；尺寸同时进入 ELK 和实际节点，长名称两行及状态不会超出绘制护框。人物缩略图采用与手机一致的顶部头像构图，原场景全幅居中，完整原图仍在详情中。

网页调查脉络也使用原稿金/蓝按钮，至少 44px，名称 15px、数量 13px、栏目标题 14px，长名称完整换行。关系图已知人物照片使用透明立绘装裱，工具放在银蓝托板上；装饰不拦截点击。筛选、放缩和详情返回保持，切换到手机清除隐藏脉络筛选，不丢搜索或类型。复用已采用图像，不增加素材、依赖、模型限制或游戏步骤。

资料页签、关闭、搜索/类型固定；手机照片档案单列，较宽窗口双列；原生始终使用已知资料卡。查询和类型为 16px，清空至少 44px；案件姓名 17px，类型 13px，身份/关系 14px。只展示已审核资料与实际存在的推测，重复数量和未知秘密不显示。网页关系图按需加载，失败返回同一照片档案；APK 不打包不用的桌面图和 worker。

人物/场景详情保留原照片比例、身份与关闭；已知正文、来源独立滚动，来源默认折叠并有明确箭头。连续关联查看/返回保持查询、队伍和草稿。手机返回先退资料链，桌面 Escape 关闭当前详情，Tab 仍属于外层资料；关闭回真实入口，不能抢已移动的焦点。

AI 设置的连接折叠栏使用与声音鸣谢一致的银蓝绘制框，15px 标签、至少 44px 点击，沿用原设置图标与开合箭头。点击和回车仍由原生 details 处理，悬停/按下轻微改变亮度；减少动态时关闭过渡。原字段顺序、错误定位、正文滚动、固定关闭/保存与玩家连接优先保持，不增素材或步骤。

存档删除也沿用浅蓝原稿按钮、原垃圾桶图标和深红文字，15px、至少 96×44px；金色载入保持主操作层级。正常/悬停均保留危险文字辨识，禁用沿用统一状态。确认仍在原记录就近展开，默认聚焦保留；取消回原删除入口，写入成功后才移除，失败记录和当前行动保留，不增加操作步骤。

调查菜单按调查记录/设置/导航分组，手机从下部打开、网页靠右，关闭与继续固定，列表内部滚动。局内读取存档先选择记录，首页继续保持一键接续；删除确认就近显示，保留焦点优先，等写入成功才移除。声音、AI 设置、原生退出也保持固定返回/确认和独立正文滚动；输入法占位不滚走整张弹窗，失败保留当前填写或行动。

骰子使用专门绘制的命运面板，层叠银框、点数区、圆弧骰子舞台与独立结果签牌，保留原 426×246 空骰面与 30 帧透明动画、原字体、计时和唯一完整结果。总点数/骰面来自锁定结果，确认后继续；不重复通用失败/成功，也没有十位/个位冗余标签。说明见 [骰子资源](../assets/ui/dice/README.md)。

等待使用 15px 静止字句和精绘银蓝钢笔尖，笔尖装在 24×24px 透明容器内，只有 3.6 秒明暗循环，减少动态时静止；不命中、不产生额外朗读。保持 24 句本地文案、每 8 秒轮换、一轮不重复、36px 等待行与原朗读状态。 等待行位于剧情滚动区之外的固定页脚，原标题分隔线在已有 10px 留白内绘制；长行动、窗口变化或回看旧记录时仍完整可见，正文不会被覆盖。回复完成后释放这 36px 给正文，面板总高度保持。短反馈在顶栏下，完整换行，不盖住底部操作；模型格式/内部规则原文留开发诊断，玩家只见真实可采取的恢复操作。

## 工程与验收

`game-ui.css` 管公共素材、颜色与状态；`portrait.css` / `desktop-game-layout.css` 管主屏分配，组件样式管各自结构。固定资料入口和首页声音入口明确保留定位，不能被共享按钮的相对定位覆盖。`src/android/mobile.css` 仍是导入桥；APK 总是竖屏，网页 ≤700 CSS px 共用手机结构，断点切换不重置队伍或草稿。

原生网络、模型 client/adapter、授权 APK 默认配置、加密存储、案件 reducer、骰点和剧情规则不因视觉重构变化。应用图标继续使用 [原美术图标](../assets/ui/app-icon/README.md)。旧网页基线可从 Git `118cf49` 恢复。

完整检查包含单元、生产构建、浏览器和正式签名 APK 原生回归；实际原稿与页面并排比较，覆盖单/双/四人，320×568、390×844、430×932、宽竖屏、桌面与 300px 输入法窗口。当前记录见根目录 [design-qa.md](../design-qa.md) 和 [重构计划](plans/2026-10-09-artist-ui-rebuild.md)。
