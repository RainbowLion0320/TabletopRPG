# 《雾中消逝》交互 UI 规范

0.4.32 案件搜索/类型使用现有黄铜护框，56px 搜索底板容纳 44px 清除按钮，类型和推测操作至少 48px。输入/类型 16px、操作 15px；档案姓名 17px，类型 13px、身份/关系 14px，脉络标题 14px。手机版收掉重复数量摘要，保持可访问页面标题和固定搜索/筛选，记录单独滚动。原照片、查询、筛选、关联返回与关闭焦点保留。APK 不附带桌面图文件，网页图失败仍可查看原照片档案；技术原因只留开发诊断。

0.4.29 回合恢复和窗口调整不再递归触发尺寸通知。只将观察回调中的换行宽度调整合并到下一帧，打字和普通窗口变化仍即时适配；离开/换行动人清理旧回调。沿用原输入高度、焦点与草稿，不通过吞掉错误或添加玩家提示解决。

0.4.28 队伍资源卡由组件维护样式，复用档案护框：姓名 14px、数值 13px、标签/行动状态 12px，最小高度 48px。已提交只用明确文字区分，不淡化整个属性卡；行动中保留黄铜强调。HP/SAN 的标签与数字整体排列/换行；单人维持一条，手机多人双列，原生竖屏宽度至少 760px 才用四列。正常窗口全队可见可点，320px 较长行动也不裁切边缘；300px 短窗口沿用收起队伍条。点开/关闭实时档案保留行动人、草稿与属性。

0.4.27 保存等短反馈位于固定顶栏下方，复用绘制档案与 15px 文字，完整换行且不遮挡底部数值/行动、不拦截触摸或焦点；展开剧情的短确认位于右侧空位，保留 NPC 名牌。短确认 1.8 秒，超过 16 个字符的说明四秒；替换和离开游戏清理旧计时器，同一 polite/atomic 区域供读屏播报。AI 保存只写「AI 设置已保存」。手机操作行按完整内容分配高度，保留既有短窗口上限与收起规则，场景先让出空间；桌面将结案的场景/剧情/操作网格用于全部阶段，避免多行输入挤掉队员卡。无额外控件或素材。

0.4.26 检定与恢复提示复用同一绘制档案：标题 16px，说明/按钮 15px，操作至少 44px。完整文字按空间换行，正常手机窗口保留全部队员卡和剧情阅读；桌面也收起该阶段不可编辑的输入行，结束后恢复原输入，避免队员被挤住。材质由组件样式维护，清理旧分散覆盖。

0.4.25 AI 设置标签、提示与底部操作至少 15px，输入 16px、触控 44px。保存缺项直接定位对应字段，错误就近显示并供读屏关联；仅地址错误展开连接设置。键盘占位保持当前字段可见，只滚动字段正文，关闭/保存固定，返回游戏保留原草稿。

0.4.24 载入旧记录时，将原调查员的过期包内图片地址恢复为当前立绘，头像入口与档案中的人物不会因升级失效；显式自定义图片保留，不改变实时属性、行动与骰点。

0.4.24 新版网页与 APK 使用相同的场景/立绘压缩和尺寸策略，保持完整构图与透明边缘；正式原图留存用于后续美术迭代。绘制 UI、字体、人物颜色、布局与阴影不变，移除未引用的暗版背景副本。图片生成缓存共用且只清理过时条目，不叠加一套资源或新的玩家控件。

0.4.23 长篇剧情在一次渲染内共用已知术语与人物颜色表，减少输入时的重复历史扫描；状态变化仍重读完整资料，逐条 AI 提示互不影响。所有原文、标记颜色、详情入口和阅读位置保留，不裁切旧记录，不新增控件或资源。

0.4.22 剧情标题采用同一行的有界网格：已知 NPC 名牌复用档案底板，展开与新内容复用黄铜框，三个入口均至少 44px。名牌手机 14px、桌面 16px，角色身份 12–13px；320px 且有新内容时隐藏身份，名称必要时省略但完整可访问。工具尺寸和标题固定，不挤入正文滚动；普通展开/收起有明确名称，资料关闭回原入口和阅读位置。样式归组件，移除旧 28/32/40px 及全局覆盖，无新增素材。

剧情阅读在新回复到达前读取实际滚动位置，对照上一条可见记录的起点；不依赖可能尚未处理的滚动事件标记。正在回看的位置保持不动，由「新内容」主动跳转，载入替代历史仍进入其最新记录。

0.4.39 长音轨只缓存当前场景、播放中与未淡出的内容，淡出结束释放闲置解码数据，短音效保持复用。已解锁音频设备恢复后自动接上当前已开启的音乐/环境声，暂停期间完成加载的音轨也可继续；过时短音效不补播，玩家无需再次触摸。原首次交互、后台暂停和静音偏好保持。声音面板复用档案底板、皮革与黄铜控件，分组文字/百分比/试听/鸣谢正文为 15px，简短记忆提示 14px；关闭、开关、滑杆命中区、试听、展开与署名/许可链接至少 44px。原生推子保留键盘操作并明确读出百分比，零音量和音效关闭禁用试听，关再开不重置数值。标题/关闭独立于内部滚动，外框 clip 阻止焦点带动整个弹窗；鸣谢只在需要时展开。手机、宽竖屏与桌面共用组件样式，无新增图片或操作。

0.4.20 结案区使用既有绘制档案底板，标题 16–17px、摘要 15px、回顾/返回与队伍卡至少 44px。手机摘要限两行，完整原文在进度页，底部内容保留最小高度，场景先让出空间，剧情仍至少 140px；不让第二排队员被内部滚动裁掉。500px 以下收起重复摘要，300px 以下收起队伍条并保留回顾/返回；正常手机高度可直接查看每位队友。桌面将结案正文、动作与队伍依次排开。已结案首页写「回顾调查」，资料关闭回实际入口；不增加图片、剧情或结算规则。

0.4.0 以手机竖屏为优先，统一 APK 与新版网页。视觉来自现有骰子美术与 1920 年伦敦调查故事：旧黄铜、深色皮革、档案纸页和刻印文字。场景与 NPC 保持原图；装饰集中在边缘，正文内区安静。

0.4.7 将主要操作改为实心旧黄铜，搭配深墨文字；调查员卡使用独立绘制的皮革档案底板，保留照片护角和细边。选角优先显示身份、简述、两项擅长技能与 HP/MP/SAN/幸运；其余属性、完整技能和背景按需展开。选择为原生 checkbox，整张资料区可点击或通过空格选择，详情操作独立。手机维持单列，网页宽屏双列；两端的队伍摘要与进入按钮均固定在底部。展开资料在列表内排布，不覆盖后续角色。详见 [第一批控件优化](reviews/2026-10-08-ui-polish.md)。

## 控件与状态

0.4.37 调查员档案、照片护框、属性格、队友与分类页签复用现有绘制档案/黄铜材质。手机核心资源两列排列，标签与上限为 14px、当前值 22px；基础属性标签 14px、缩写 12px，身份和背景标题 14px、技能职业标签 12px。队友与分类文字 15px，关闭、分类、队友、清空搜索均至少 44px。技能表和装备背景正文仍为 15px，普通技能值 17px、表头 13px。表头固定，重复说明只留可访问 caption；正文独立滚动。同次查看切页保留位置，换人/新查询回开头，清空后继续聚焦输入。300px 手机窗口收起身份细节、减小边缘，队友改横向滑动但不隐藏，保留可读正文。样式集中到 `investigatorSheet.css`，无新位图。

0.4.18 有当前调查或有效存档时，「继续游戏」排在首位并使用实心黄铜主按钮，「开始游戏」保留为次操作。首页用既有档案底板列当前地点、队伍和公开故事时间；手机限宽 320px，姓名完整换行，短窗口收起时间。只在焦点位于页面 body 时聚焦主操作，不抢正在使用的其他控件。导航与取消选角保留当前调查，新的样式归属 `title-screen.css`，移除旧最近存档提示规则，无新图片。

0.4.17 进度和日志复用档案九宫格材质，正文 15px/1.8，时间/状态 12px；长字和换行完整折行。当前目标优先，旧目标用 44px「调查回顾」展开，完成内容保留可读文字；初始无已知线索时收起空统计。已公开局势用小黄铜进度条显示原值，不引入倒计时。日志搜索为 16px 输入、44px 清空，始终位于内部滚动列表上方；清空保持输入焦点，切页返回原查询/位置，关闭资料重置。移除旧圆角卡与分散小字规则，无新增图片。

0.4.16 手机顶部资料图标固定为普通 44px 按钮，无拖动提示或隐藏位置；小幅手指漂移仍正常打开，关闭恢复入口焦点。桌面入口可上下调整，拖动完成/取消均清除视觉状态，后续点击及回车/空格照常使用。删除已停用的旧手工画布、旧列表卡样式，仅保留现行手机档案与桌面关系图规则。

0.4.15 桌面图卡复用手机档案底板和照片，类型以低饱和色标区分；当前资料亮框，其他脉络减淡而仍可操作。缩放/查看全部关系为 44px 中文图标工具，达到缩放上下限时禁用。详情打开/关联切换时按实际画布适配当前资料，关闭恢复玩家视角；查询/过滤或尺寸变化才重新定位，普通阅读保留手动镜头。大范围关系优先保证当前卡可读，减少动态效果关闭过渡。图卡/工具规则集中在 `case-board-flow.css`，删除旧全局样式；手机仍使用档案列表，无新增位图。

0.4.34 详情复用档案底板、现有照片与 7px 绘制照片护角，人物/场景完整 contain。身份/标题/44px 关闭常驻上方，身份、关系及记录标签 14px，小标题、已知正文和来源 15px；正文行高 1.85。关联资料为 52px 绘制操作，支持继续查看及上一份返回。信息来源是 48px 黄铜折叠控件，以装饰箭头标明状态，默认折叠，未知秘密数量不显示。手机详情独立接管键盘和系统返回，桌面详情只接管 Esc，Tab 仍在整个资料页内；关闭回原资料，外部已获得焦点时不抢回。300px 窗口隐藏照片保留阅读/退出。桌面图卡为原生按钮，回车/空格打开资料且没有重复 Tab 停留。样式集中在组件 `record-detail.css`，无新增图片或资料规则。

0.4.13 标题动效使用现有 WebM 和同画面 29KB WebP 封面；视频开始前或不可播放时保留场景，减少动态效果/切后台仍暂停。介绍页也复用正式场景，旧 GIF/占位 SVG 从当前工作区移除，不再积累同画面的冗余资源。

案件卡复用档案底板，58×74px 照片区展示人物立绘，场景缩略图完整 contain；事件/推测/物证无照片时用已有线图标。类型、姓名、身份、最多两条关系和打开箭头分区，当前文字 13/17/14px；小于 640px 单列，较宽资料列表双列。只有实际存在推测才显示开关。资料页签支持左右/Home/End 键和选中状态，标题/关闭/搜索/筛选固定，列表内部滚动。清空搜索恢复输入焦点，关闭详情回原卡，原生宽竖屏保持列表。重复统计、零项摘要和剧本总线索数不展示给玩家。

0.4.38 等待提示保留 24 句本地文案，每轮打乱、每 8 秒轮换且一轮内不重复，15px 固定高度与原逐字动效保持，减少动态效果设置继续有效，朗读器不反复播报每句。安卓解析/加密记录损坏不展示底层诊断或原文；单条损坏隔离后以既有通知简短说明，其他有效记录仍可继续。通知复用绘制护框和 44px 关闭操作，位于顶栏下方以留出输入区。退出使用独立档案卡，15px 正文与操作、48px 按钮、固定确认和可滚动说明；首次焦点到「留在游戏」，保存等待禁用双按钮与返回，失败就近提示并允许重试/取消。保存确认包含等待中加入的更新与删除。复用现有图片，不增加素材副本。

0.4.35 局内「读取存档」先选记录再载入，合并原直接读取最近记录和管理的两个入口；关闭保留当前草稿，首页仍一键续玩。读档外框、关闭和保留/删除确认均复用绘制档案/黄铜护框；时间与队伍姓名 14px、操作和确认 15px，手机三/四人照片与完整姓名上下排布。存档卡复用绘制的档案底板，卡片内按场景、时间、队伍照片与姓名、操作排布；最近有效存档带小标签。删除为安静的图文入口，载入为 44px 黄铜主按钮。标题、关闭、底部返回保持固定，只有列表滚动；320px 手机、300px 键盘窗口和桌面兼顾。删除确认直接展开在对应卡片内，焦点先到「保留存档」；确认与取消自动在列表内露出，避免整张弹窗滚动。写入期间禁用操作，失败只在该卡片提示，删除后焦点到剩余存档的载入或关闭。版本不兼容的记录保留，界面不展示内部原因原文。

0.4.10 在档案内切换队友时保留技能查询，便于比较同一技能的值与阈值；关闭重开清空查询。正式 APK 的默认 MiMo 已可直接使用，设置入口保留，已保存的自定义服务优先；密钥继续默认遮蔽。

0.4.41 建议行动使用现有绘制档案的 4px 护边，14px 文字、44px 目标；提交/下一位使用 15px 文字、48px 目标和原实心黄铜，窄屏收紧左右边距。尺寸与建议材质归 action-controls.css，移除旧全局/手机/主题缩小覆盖。手机建议横向滚动，桌面长建议可在按钮内换行。行动输入使用可写多行的暗槽：空白保持 44px，手机最大 96px，桌面最大 104px；手机键盘窗口 300px 及以下限制为 66px，更长描述仅在输入框内滚动。手机回车换行，显式按钮确认；桌面保留回车确认、Shift+Enter 换行。手机网页 textarea 与其他表单一样为 16px，避免输入缩放。多人当前行动卡显示「行动中」，完成宣言显示「已提交」；等待 DM / 检定时收起这两个临时标记。查看属性仍只查看，不改行动顺序或草稿。

剧情最新回复从开头跟随；用户回看更早的记录后，新消息保留其阅读位置，固定标题区出现「新内容」。点击后读取最新回复开头、焦点回到剧情记录并收起入口，手动读到最新也会收起。加载另一份存档重新从其最新记录开始；隐藏系统消息不移动正文、不触发提示。

0.4.40 的调查菜单按「调查记录 / 设置 / 导航」分组，分组文字 14px、操作文字统一 15px，列表与「继续调查」至少 48px，关闭为 44px 图标。手机从底部展开，网页靠右；固定关闭和「继续调查」，列表按需滚动。字号、尺寸与菜单黄铜排列归组件所有，不随通用手机样式加载先后缩小。菜单是真实对话框，Tab 不进入背后行动区，Escape / 系统返回关闭当前最上层；声音面板关闭先回菜单，菜单关闭回到原入口。取消不更改行动草稿。

AI 配置默认显示服务商、API Key 和模型；官方 OpenAI 的地址/协议在「连接设置」中，MiMo、自定义及已保存的非默认连接自动展开，原参数不被替换。新表单不提前标红，保存时仍按真实协议校验；错误提示紧邻对应字段，保存后焦点直接定位，输入更改清除旧反馈。密钥默认遮蔽，可临时显示核对，重开再次遮蔽。字段区和字段反馈独立滚动，标题、关闭和保存固定；输入法占位只保持当前字段可见。保存期间禁用编辑与退出，重复提交只写入一次，写入失败保留填写内容。连接和菜单的布局分别由组件样式维护，黄铜护角复用既有美术。

| 开关与音量 | 方形机械拨片、黄铜推子 | 保留 switch 语义和文字；关闭单个音轨只禁用其滑杆 |
| 调查员卡 | 档案框与四种属性色标 | 勾选章、底色及边框共同提示选中；已行动仍可读 HP/SAN |
| 弹窗与资料 | 细雕角外框，内容内部滚动 | 关闭、保存与确认保持可达，原焦点和返回层级不变 |
| 消息与提示 | 账簿式叙事、右侧行动条、细线系统提示 | 装饰不盖剧情，不公开 DM 内部信息 |

手机主输入至少 44px、提交 48px，主要菜单 48px，首页主要按钮 52px；建议、展开和属性等次操作至少 44px。320×568 四人游戏中，剧情面板高度不低于 140px，并可展开阅读；空间不足时先收窄场景展示区，完整图片仍等比例容纳。

0.4.2 展开阅读有明确边界：从章节/地点栏下方扩展到行动区上方。NPC 名牌和收起按钮固定在面板顶部，正文独立滚动；两级信息栏不会漂在剧情上或被剧情遮住。展开时菜单、资料与底部输入仍可用，收起恢复场景。极短键盘窗口继续优先保留阅读与输入。验证见 [展开阅读验收](reviews/2026-09-09-expanded-reading.md)。

## 调查员档案

0.4.6 的回合异常属于临时操作反馈：底部只保留一条可重试通知，不插入剧情记录。格式/语义错误统一用可理解的说明，不展示工具名、内部规则或未解锁地点；网络/鉴权错误保留实际类别，只显示固定操作建议，过滤接口原文。成功后通知消失，旧存档中的内部错误也不再显示在剧情或日志里。KP 笔记移至开发诊断入口，配置问题留在设置弹窗。多人检定记录包含角色与技能，骰点只出现一次。

选角页从 0.4.4 起在所有竖屏尺寸保持一行一张卡，包括逻辑宽度达到 600px 的手机与平板。立绘在左、资料在右；列表、顶栏与底栏居中对齐，最大宽度 720px。长列表纵向滚动，已选人数和进入按钮固定在底部，属性展开不改变选中状态。见 [选角验收](reviews/2026-09-09-portrait-selection.md)。

局内角色查看采用黄铜档案面板：44px 行动头像与至少 48px 队员卡为入口，正文玩家姓名共用同一档案。顶部为小幅立绘、身份与固定关闭按钮；多人按姓名切换查看，手机两列排列。属性、技能、随身与背景分为三个页签；HP/MP/SAN 显示当前/上限，幸运使用当前值，八项基础属性分格展示。技能按实际数值排列，可搜索并对照三档检定阈值；搜索框在滚动区外，列名留在顶部。底部内容独立滚动，300px 键盘占位时收起肖像并让队友横向滑动，仍可比较队员和关闭。面板仅供查看，关闭后回到原入口并保留行动草稿。验收见 [调查员档案](reviews/2026-09-09-investigator-sheet.md) 和 [当前控件验收](reviews/2026-10-08-ui-polish.md)。

## 字体、颜色与材质

- 控件和标题用已有字魂云雀宋，呼应骰子；剧情、资料正文和技术配置值保留宋体/衬线字体栈。原许可标注见 [字体说明](../assets/fonts/README.md)。
- 正文 `#e7ddcc`，辅助文字 `#b9ad98`，黄铜 `#ae8b52`，章节标题 `#dfc58d`，深底 `#11100e`；错误使用低饱和红色。章节与场景的对比度按实际渲染校验。
- [UI 材质](../assets/ui/chrome/README.md) 采用九宫格边框，保留角区；纹理轻微平铺，图标继续用 Lucide。全部文字实时渲染，不拉伸控件截图。
- 金色内焦点框不会被滚动容器裁掉；禁用不只靠透明度区分。按下动画 130ms，尊重系统减少动态效果设置。

## 工程边界

0.4.1 应用标识使用美术交付的深蓝底白色眼睛图案，覆盖安卓桌面/启动画面、网页标签与手机快捷图标；平台图标尺寸与裁切规则见 [图标资源](../assets/ui/app-icon/README.md)。

`src/styles/game-ui.css` 管材质与状态，`src/styles/portrait.css` 管手机主界面布局；选角的组合与响应式规则统一在 `src/components/setup/character-setup.css`。通用按钮使用低优先级 `:where`，让主操作及状态样式可以正常覆盖。`src/android/mobile.css` 仅为导入桥。`src/platform/layout.ts` 在渲染前添加 `fog-ui`；APK 总是启用 `portrait-ui`，网页宽度不超过 700 CSS px 时启用同一竖屏布局。

断点变化同时更新布局和选角底部操作，不重置队伍或输入草稿。宽网页保留宽屏结构。手机网页输入/选择器为 16px，避免输入时自动放大；viewport 开启安全区覆盖与 `interactive-widget=resizes-content`，让支持该选项的 Android Chrome 随键盘缩小内容窗口，依据 [Chrome 官方说明](https://developer.chrome.com/blog/viewport-resize-behavior/)。

Native HTTP、API 配置、加密存储、骰点和游戏规则不变。2026-09-28 经用户确认，共享网页与 APK 改进合入 `main`，旧网页版本保留在 Git 提交 `118cf49`。验收见 [0.4.0 UI 检查记录](reviews/2026-09-09-ui-system.md)。
