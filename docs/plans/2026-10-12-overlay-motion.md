# 0.5.60 面板打开、关闭与切换动效

沿用美术原版图标、冷蓝银框和手机竖屏布局。旧版本的淡入幅度很小，关闭直接移除；本轮补齐可辨认的成对过渡，动画不接管游戏结算。

1. 共用面板：菜单、AI/声音设置、读档、人物详情、调查员档案、案件详情、资料、骰子和安卓退出确认统一轻抬起/淡入，手机菜单从底部舒展；关闭轻收回/淡出。
2. 关闭语义：状态和回调立即生效、焦点立即返回，保留的170ms画面为 inert/aria-hidden，不能再点、抢焦点或拦系统返回。快速重开取消旧清理；后台或减少动态立即移除。
3. 切换与控件：页签内容短距离淡入，保留原正文位置、固定标题、草稿及返回链；按钮按下轻缩、释放复位。等待、场景和新剧情沿用原持续反馈，不重播历史。
4. 全面验证：关闭中的交互和焦点、嵌套返回、快速重复开关、读档与API写入只执行一次、背景清理、减少动态、窄/短屏、单/双/四人及正式签名包原生触控/返回/输入法。
5. 交付：更新0.5.60/versionCode108、产品/技术/设计/wiki说明；原签名、原图标和授权APK默认配置核对，保留最近两包，提交并推送主分支。

不增加动画库、新玩家开关、搜索功能、模型请求或提示词限制。
