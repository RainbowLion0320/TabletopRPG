# 档案阅读会话与内容过渡接续

## 目标与范围

调查员档案快速关闭后重开，延续当前页签和每名队员、每个页签的阅读位置；阅读内容在 190 ms 内连续切换时，接续当前视觉姿态，避免固定起点造成闪动。本批仅修改 `InvestigatorSheet.tsx`、共享 `useReadingMotion.ts`，不改存档确认区、外层开合生命周期、美术和游戏规则。

## 最小实现

- 档案的阅读会话随 `motion.present` 结束。逻辑关闭仍立即移除对话框所有权、恢复焦点并设置 `inert` / `aria-hidden`；170 ms 退出尾部仅保留当前视觉与阅读状态。同一 DOM 在尾部内重新打开，保留当前页签和每人每页签读位。真正 `present=false` 后清理会话，新打开从属性页、零读位开始。
- 档案正文的阅读动效同样以 `present` 为视觉会话边界。快速关闭、重开相同内容无需取消或重新播放正文动效。选中的查看对象仍只决定档案内容，不更改行动队员或草稿。
- 共享阅读 hook 仅增加一个 ref。旧动效仍在运行时，cleanup 从闭包中的旧实际节点读取当前 opacity / transform，再取消旧动效；下次 layout effect 仅在同一节点且仍启用时消费这个姿态，作为新的 190 ms 起点。
- 首次出现、已结束的动效、新 DOM 继续使用原 opacity .45 / 位移 3 px 的短淡入。disabled、减少动态和后台均清理接续样本；中途改变偏好或进入后台立即取消动效。StrictMode 同节点重放接续当前姿态。
- 不增加 React 状态、延时、全局扫描、逐帧循环或依赖；操作、确认、滚动和焦点无需等待动画。

## 验收

1. 单人、双人、四人，在技能和背景页分别滚动；45 / 80 ms 退出尾部内重开相同档案，DOM、页签与读位保持；实际退出结束后新会话回属性页，全部队员页签读位清理。
2. 查看队友与切页签时，各自读位独立恢复，行动队员、多行草稿、焦点和返回键行为不变。
3. 首次正文淡入仍有 190 ms 真实中间帧；25 / 55 / 85 ms 连续切页或切玩家，从相同节点的当前 opacity / DOMMatrix 接续，外层根不重播。
4. 减少动态及后台中断立即结束正文动效，无残留样本；完全关闭后重新进入仍有原首次淡入。同页操作不重播。
5. 类型检查、差异格式检查及定向浏览器回归；原生组由主线队列验证 WebView 110。所有证据与测试改动由指定测试代理整理，不操作用户当前游戏。
