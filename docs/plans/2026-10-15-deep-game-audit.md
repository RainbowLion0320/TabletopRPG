# 深度游戏检查与精简

目标是提高现有《雾中消逝》的游玩可靠性与流畅度，沿用美术原稿、手机竖屏优先和单人默认。对确认的问题完成修复与验证，不用新增玩法、提示词限制或工具型控件填充本轮。

1. 检查首页、选角、新手引导、自由行动、等待与失败恢复、真实检定、案件资料、角色档案、结局和返回接续，覆盖单／双／四人。
2. 审查AI解析与重试、多人声明合并、骰点与资源结算、剧情事件和已知信息边界；模型回复用受控测试，不消耗玩家真实服务。
3. 检查手动存档、安卓自动续玩、并发保存、后台／输入法／系统返回，以及过期会话是否污染新调查。
4. 实际检查手机窄屏、短屏、普通竖屏与桌面；从可复现的卡住、丢草稿、错误说明、遮挡与重复操作着手精简。
5. 先以针对性测试重现问题，再修复；完成规定的逻辑、生产构建、浏览器和安卓重点验证，记录实际证据与检查边界。
6. 同步产品、技术、GDD／HTML、UI、Android和Wiki；制作原签名APK、验证原美术与配置隔离，保留最新两包，提交并推送主分支。
