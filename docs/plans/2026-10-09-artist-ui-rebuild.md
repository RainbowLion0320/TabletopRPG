## 目标与边界

- 直接使用美术原有的伦敦雨雾背景、动态背景、标题和金色/浅蓝按钮。文本与点击仍是真实控件，不把整张首页图当成界面。
- 延续原稿的冷蓝雾色、象牙白细线、成对珠点和少量四芒星。缺失的面板和图标底板按这套语言补齐，正文区域保持安静。
- 保留角色、故事场景、NPC 立绘、已知证据、骰子、字体、声音和已确认的手机布局。视觉重构不新增跑团限制、模型请求、资源数值或存档格式。
- 保留单人默认、多行行动、队友草稿、固定任务条、故事展开上限、选角一行一人、头像属性、读档选择记录和首页一键继续。
- 原始 PSD/AI/大 GIF 留在用户素材目录，不提交仓库。只导入实际使用的运行时资产，记录来源和导出方法；完全替换后再移除闲置旧 UI 图，不能误删场景、骰子、字体、签名和工具。

## 执行批次

1. **收尾已验证的行动建议修复**：去重发生在现有限额之前；空输入提示在小手机内不裁切。通过正式 Android 回归后独立提交推送。
2. **原稿资产与公共规范**：资产来源、字体/色彩/状态变量、原按钮和面板切片、图标底板；清理旧黄铜/皮革规则，不靠追加整层覆盖掩盖旧样式。
3. **首页与选角**：原标题和雨雾背景、首页按钮、设置入口、续玩摘要；竖屏一行一人、照片/身份/属性/选中状态、固定底部进入。
4. **调查主屏**：场景与 NPC、固定顶部任务/菜单/资料、普通与展开故事、建议、当前头像、多行输入、提交/下一位、队友卡、思考/恢复/结局状态。
5. **资料和档案**：调查员核心数值/技能/背景/队友比较；资料抽屉、已知人物/地点/线索、照片详情、来源跳转、手机案件卡/桌面案件图及关系查看。
6. **系统弹窗与检定**：调查菜单、AI 配置、声音、存档选择/删除/读取、退出确认、骰子待投/动画/结果/多项检定、失败恢复提示。开发诊断页也移除过时视觉，但不向玩家开放诊断。
7. **整套视觉与交互回归**：按下表核对每个界面，修正短窗口、文字换行、焦点、返回层级、加载/错误/禁用/选中状态和控件命中。
8. **发布与收拢**：同步事实源与 Wiki；完整单元/构建/浏览器和正式签名 Android 回归，核对 APK 版本/证书/内容/密钥隔离，成功后仅保留最新两包和校验文件；提交并 push。

每个可独立验收批次及时提交推送。未完成覆盖不能称作整套重构已交付。

## 验收方法

- 首页原稿与实际页面必须同屏对照，桌面按 2048×1136 原稿尺寸核对背景/标题/按钮，再在手机构图中保留同一视觉身份；截图不是交互验收的替代。
- 浏览器核对 320×568、390×844、430×932、宽竖屏和桌面；普通与 300px 输入法短窗口、文本缩放、减少动态、触摸/键盘焦点均检查。单/双/四人分别恢复草稿、打开属性/资料、提交和保存读取。
- 保持控件至少 44px 可命中、主要确认 48px，正文和动态长名称不会撑破框架。紧凑依靠间距和层级，不缩小关键文字或隐藏玩家必需信息。
- 对照颜色/字体/边框/裁切/透明边缘与控件状态，不允许仍散落旧黄铜皮革图、硬编码棕色或默认网页按钮。
- 完整 `npm test`、`npm run build`、`npm run test:smoke`；正式 `npm run android:test` 在专用 QA 模拟器运行真实 WebView/原生网络/加密存储/Activity 恢复/声音和系统返回。
- AI 回归用受控离线回应，不消耗玩家 token。模型只通过现有 client/adapter；不输出或提交密钥。授权 APK 默认仍可被玩家保存配置覆盖。
- 记录最新根目录 `design-qa.md` 的对照证据、已修问题与实际限制；交付前解决 P0/P1/P2。保留真机输入法/系统字体差异的验证边界。
