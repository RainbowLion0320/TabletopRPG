# 首页与局内短反馈的可见性和进出动效

## 已确认的问题

网页首页和 Android 入口首页在保存 AI 设置后直接渲染无定位的 `.toast`。独立浏览器实际点击、纯测试配置保存的证据显示：390 × 844 视口中提示位于 y=844–864，父级 root / body / html 均 overflow hidden，玩家看不到成功反馈。局内使用的 `GameNotice` 已有定位和银蓝画框，但通知到期会立即卸载，只有固定起点入场动画。

## 最小实现

- 共用提示迁入 `src/components/shared/GameNotice.tsx` 与同目录样式，首页、Android 外部画面和局内只复用这一实现；保持首页不依赖局内业务组件的原工程约束，不增加包装组件或放宽架构检查。

- 首页与 Android 非游戏画面复用 `GameNotice`；局内保留原组件。Android 外部实例按 screen 分会话，只有首页接收消息，选角为空消息，离开首页立即卸载旧画面；进入游戏仍沿原 controller 清理流程。恢复提示 `.android-notice` 仍是用户确认的独立 alert，不改业务。
- 实际 Android 首页保存设置、进入选角后在 152.2 ms 内返回首页，会重新展示旧成功提示。首页开始选角因此复用网页已有的 `game.restartSetup()`，在切屏前清理原通知与临时控制器任务；不改通知 TTL、controller 实现或持久会话。修复后同一真实流程的即时快照中 count=0、text 为空，不能靠等待 1800 ms 到期取得空提示；证据为 `android-navigation-before.json/png` 与 `android-navigation-after.json/png`。
- `.game-notice` 保持一个持久 polite / atomic live region。内部唯一 `.toast` 使用现有 `useOverlayPresence(message)` 和 `useOverlayEntry`，首次出现做 160 ms 透明度与 3 px 位移动效；逻辑到期立即 inert / aria-hidden，只有原文字画面保留退出 150 ms，170 ms 后释放。
- 不按文字重新挂载节点。新消息原地替换，退出尾部重新通知沿同一节点当前姿态接续；旧退出计时不会删除新消息。通知不包含操作、不取焦点、始终 pointer-events none，保持银蓝边框、15 px 正文和既有定位 / 层级。
- Android 开发入口真实长失败反馈验证发现，320 × 568、四边 20 px 安全区、单人且展开剧情时，提示 y=88–150 与 NPC 标题 y=69–113 相交。限定高度至少 301 px 的竖屏展开剧情后，提示实际为 y=136–198，标题仍为 y=69–113，垂直间距 23 px；captionClear / inside / controls / aboveDock 均通过，15 px 字体、银蓝画框、操作区 top=347 和阅读区 top=240 不变。证据为 `output/ui-notice-motion-2026-10-13/android-long-caption-failure.json/png` 与 `android-long-caption-after.json/png`；仅证明该实测场景，不外推全部人数或提示。300 px 短窗沿原安全位置，不覆盖其布局规则。
- 不改 `useToast`：短反馈 1800 ms、超过 16 字的反馈 4000 ms，相同或不同新反馈仍清理并重设原逻辑计时；保存、载入、行动与导航不等动画。切换画面随原组件卸载，不把过期画面带到下一屏。
- 移除全局 `.toast` 固定起点关键帧，避免双动画。减少动态及后台使用即时过渡；真实 document.hidden 到期或关闭时沿既有 presence 立即释放，持久 live region 保留。

## 验证范围

1. 首页实际 AI 设置保存后，消息位于视口和安全区内；网页与 Android 开发入口分别核对，使用纯测试 endpoint / key / model，不请求玩家模型。
2. 单人、双人、四人；320 / 390 竖屏、1440 桌面、300 px 短窗；局内普通 / 展开剧情下通知不遮挡操作、队伍与 NPC 标题，不改变阅读高度、滚位、草稿或行动角色。
3. 保留真实 24 RAF 轨迹，随后等待原生 finite transition 自然完成。入场 / 退出有中间透明度；逻辑清空当帧即退出 AX；快速替换及尾部复来使用同一节点，无旧计时误删。
4. 1800 / 4000 ms 逻辑期限、相同通知重新计时、减少动态和后台起点 / 中途即时收束；无伪造 animationend / transitionend、无阻塞点击、无永久 RAF。
5. 组件回归、既有保存成功 / 失败反馈与导航检查；真实 Android WebView 的首页、局内保存、系统返回和真实 IME 独立证据，由主代理整合后验证，不把浏览器或固定窗口当作 APK / 自然 IME 证据。
