# 外层弹窗连续开合过渡

## 目标与范围

快速关闭、再次打开菜单或弹窗时，让当前画面连续过渡，避免固定关键帧从完全展开或初始位置重新播放造成跳动。维持现有银蓝美术、240 ms 入场 / 170 ms 退场、手机竖屏优先布局，以及逻辑关闭立即生效的焦点和无障碍语义。

覆盖声音设置、AI 设置、局内菜单、存档管理、DM 日志、实体详情、调查员档案、安卓退出确认、骰子弹窗、资料抽屉和案件详情，共 11 个外层。内嵌折叠、剧情收放、骰子结果 160 ms 揭晓、规则结算和存档格式不变。

## 实现

- `useOverlayPresence` 保持原样：关闭立即 `inert` / `aria-hidden`，仅保留 170 ms 退出画面；同一 DOM 在退出结束前重开可继续使用。
- 新增 `useOverlayEntry(present, existingRef)`，从既有 ref 就近获取 `[data-ui-phase]` 根。首次呈现或实际根 DOM 更换时，短暂添加 `data-ui-enter`，同步读取根和直接面板的起始样式，随即移除。原生 CSS transition 接续当前 opacity / transform；快速反向不重新设置起始值。
- Hook 不增加 React 状态、逐帧循环、定时器、全局 DOM 扫描或依赖。每次 commit 检查真实根身份，StrictMode 重放不重新播入场。
- 资料抽屉沿用常驻 DOM，按 `present` 的完整呈现周期初始化；明确替代旧横向滑入。骰子移除旧遮罩入场关键帧，保留结果内容揭晓。
- 打开使用原 240 ms 曲线，关闭使用原 170 ms ease-in。普通面板维持入场位移 12 px / scale .975，手机菜单 18 px；抽屉入场保留 10 px。退场维持 8 px / scale .985。
- 减少动态偏好或后台时，外层 transition 即时落到最终样式；后台首次打开不设置入场标记。焦点、返回键、点击处理与生命周期保持原有实现。

## 验证计划

1. 类型检查、逻辑测试、构建及完整浏览器回归由主线整合执行。
2. 浏览器与真实 Android WebView 110 逐帧验证首次开合、关闭途中重开和三次连续反向：同 DOM，opacity / transform 连续，240/170 ms 样式契约不依赖 animation 事件。
3. 覆盖单人、双人、四人；资料页签与读位、档案切换、已确认骰子结果、多行草稿不因视觉过渡丢失或重复提交。
4. 关闭即隐藏无障碍入口并恢复焦点，退出画面不可误触；减少动态和切后台中断时正确清理。
5. 再次完全关闭后打开重新入场；仅资料抽屉 DOM 常驻。无残留 `data-ui-enter`，内嵌及剧情动画时长不变。

本批仅处理外层过渡，不增加可见设置或新功能。

## 同轮整合的阅读与存档改进

1. 调查员档案过去在逻辑关闭时就重置属性页和书签，170 ms 退出尾部内重开会丢失阅读位置。会话现随真正退出结束清理；快速重开保留当前页签与每人读位，完整关闭后仍从属性页开始。实现见 [阅读接续计划](2026-10-13-reading-continuity.md)。
2. 阅读页过去连续切换时反复从 opacity .45 / 位移 3 px 播放，造成闪动。现从同一节点正在显示的姿态接续，首次呈现保留原短淡入；同页、焦点与滚动行为保持。实现见 [阅读接续计划](2026-10-13-reading-continuity.md)。
3. 存档删除确认过去立即替换和卸载，卡片高度突变会推挤后续记录。现复用自然高度过渡和单一操作行，取消即时恢复原按钮；二次确认、失败保留、读取与不兼容记录保持。实现见 [存档确认计划](2026-10-13-save-confirmation-motion.md)。
