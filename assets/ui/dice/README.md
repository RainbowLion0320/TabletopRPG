来源：美术同学交付的「骰子弹窗」，2026-09-09 接入。这里只保留网页实际使用的资源，ZIP、PSD、效果预览和原始视频不入库。

| `ui_dice_roll.webp` | 原旋转动画的透明竖向帧图 | 426 × 7380，30 帧，WebP quality 88 |

## 处理与对齐

- ZIP 文件名编码为 GBK；备注要求背景黑色 40%、高斯模糊半径 4.0。界面对应 `rgba(0,0,0,.4)` 与 `backdrop-filter: blur(4px)`。
- 0.5.0 面板换为 [首页原稿风格](../artist/README.md) 的冷蓝阅读护框，保持 639:890 的纵向布局。旧古铜面板已由此完全替换并移除；原导出记录和图片可从 Git 历史恢复。
- 静态骰子来自 PSD 的「组 4 / 组 3」，在原图 `(735,505)-(1161,751)` 的画布中对齐。结果区使用字魂云雀宋实时显示唯一完整等级，如「大失败」「困难成功」，不叠加通用成功/失败字样图；骰面只显示数字。
- 所谓「透明底」MP4 实际是无 alpha 的 H.264 黑底视频。FFmpeg 提取原 12 fps 共 30 帧，按相同骰子区域裁切，用外部黑色连通区域恢复 alpha，保留骰子内部暗纹并对边缘反预乘；最后转为透明 WebP 帧图。未引入音轨。
- 帧图使用 CSS `steps(30, jump-none)` 播放 2.5 秒。时间统一来自 `src/app/diceRollAnimation.ts`。资源解码失败显示静态骰面，检定的计时和确认流程继续正常工作。
- 保留完整字体字符集，弹窗的全部实时文字统一使用 [字魂云雀宋](../../fonts/README.md)。总点数和十位/个位数由真实结果实时排版；不使用预览中写死的「20」。

运行时入口：`src/components/game/DiceRollOverlay.tsx`、`src/styles/dice.css`。骰子舞台宽度为面板 80%，高度 33.1685%，保持 426:246 原比例；原空骰面、30 帧动画、结果来源和确认逻辑保持。
