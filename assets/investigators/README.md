# Player investigator portraits

This directory contains runtime portraits for the four selectable player investigators. Keep these assets separate from `assets/avatars/`, which is reserved for NPC artwork.

| Investigator | Delivered source | Runtime asset |
| --- | --- | --- |
| 亨利·格雷 | `亨利-格雷-透明底.png` | `henry_gray.png` |
| 艾达·华莱士 | `艾达-华莱士-透明底.png` | `ada_wallace.png` |
| 托马斯·贝尔 | `托马斯-贝尔-透明底.png` | `thomas_bell.png` |
| 罗伯特·肖 | `罗伯特-肖-透明底.png` | `robert_shaw.png` |

Runtime requirements:

- PNG with transparency, 1600 × 2000 (4:5).
- One character per file, with the face kept clear in the upper half for small party and action-dock crops.
- Background concept paintings and other original art files are not runtime assets and must not be committed here.
