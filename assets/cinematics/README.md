# 美术开场动画

来源：美术同学提供的 `D:/开场动画`，2026-10-14 接入。原始四份视频及备注保留在来源目录，未修改、未复制到工程。原片哈希和运行文件哈希见 [manifest.json](manifest.json)。

| 运行资源 | 用途 |
| --- | --- |
| `opening-portrait.mp4` | APK 与竖屏网页，1080×1920 |
| `opening-landscape.mp4` | 横屏网页，1920×1080；不进入竖屏 APK |
| `opening-portrait-poster.webp` / `opening-landscape-poster.webp` | 原片首帧，加载期间展示 |
| `opening-effects.m4a` | 纯音效版的声音，独立遵守游戏音效开关/音量 |
| `opening-music.m4a` | 从时间对齐的混音版减去纯音效版后导出，独立遵守背景音乐开关/音量 |

画面保持原构图、30fps、BT.709 与约14.87秒时长。为 Android WebView 兼容，HEVC 转为 H.264 High Level 4.0/yuv420p，MP4 使用 fast-start；画面本身无声，与两条声音通过同一播放时钟同步。音乐轨是从所给素材派生的轨道，并非美术另交的原始独立音乐母带。两声道共同开启时重组原混音；声音保持44.1kHz立体声，不增加新曲目。

播放规则由用户确认：首次启动自动播放，结束或主动跳过后记住；首页小图标可随时回看，回看不改调查或连接设置。按进入时的屏幕方向选片，途中旋转不重播，完整画面居中适配。片尾650ms叠化到原首页，跳过/异常240ms退出；后台暂停，恢复续接。系统减少动态效果时不自动播放，仍可主动回看。

重新导出使用 `scripts/prepare-opening-media.py --source <原片目录> --ffmpeg <支持libx264的ffmpeg路径>`。只提交采用的资源、导出脚本与来源记录，不保存原片、解码中间文件或多余混音副本。
