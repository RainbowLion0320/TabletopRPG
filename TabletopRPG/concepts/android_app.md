# Android 游戏客户端

731 项单元 / 67 文件通过（12.45 秒），生产构建通过，161 项浏览器通过（51.0 秒），正式签名 APK 11 组原生通过（180.676 秒）。没有付费模型调用。 最终包 11,493,516 字节、SHA256 `2f35d98b4a7395e3faabb9ce0ac48d37018f43c063dd652f432a0e0edb307e69`，沿用原签名；八图和透明边界保持，最近两包 .5.10/.5.9。

当前为 0.5.10 / versionCode 58，网页关系卡字级与头像构图和手机档案统一，原生仍用已知照片档案；等待用精绘钢笔尖和静止字句，固定页脚不被长行动/回看卷走，原轮换、阅读和多人流程保持；连接折叠栏复用精绘框，原设置顺序、触控、键盘与关闭/保存保持；存档删除使用浅蓝底板与明确深红文字，确认、记录和当前行动保持；原生保留已知照片档案，网页案件脉络和关系工具接入原稿美术；短窗口档案收紧身份区、完整查看筛选技能和阈值，表头 13px；桌面短窗口优先阅读与操作，资料拖动后缩窗仍完整可到达，头像访问全队且草稿保持；手机原布局不变。保留 0.5.3 组字候选保护、0.5.2 精绘 UI 与 0.5.1 自动保存。0.5.2 按原稿风格精绘七类专用资源：骰子命运面板、银蓝档案阅读框、透明立绘装裱、深色输入槽、方形工具底板、标题分隔线和珠光推子。首页原标题与金/蓝按钮保留，全部生产界面使用实际压缩图；层次和装饰集中在边缘，文字、立绘与触摸区域独立。骰子保留原骰面和字体，点数区、舞台及唯一结果签牌各有安全区，小屏/短窗口保持可读与可确认。新素材不添加文字、人物、模型限制或操作步骤。 0.5.1 将安卓连续行动输入的自动保存合并到最长 250ms 的有界窗口，内存续玩立即使用最新草稿；提交、换人、手动存档、返回首页、重新选角、切到后台、页面离开和退出立即保存最新内容。完整历史、多人草稿和锁定骰点保留，存储格式与加密方式不变。强制杀进程且未收到生命周期通知时，最多一个尚未写入的输入窗口可能无法恢复；不把异步保存描述成绝对零丢失。骰子揭晓沿用已加载的静态骰面，避免替换图片时短暂空白，原计时和确认逻辑不变。

共享 UI 全面使用用户指定原首页的冷蓝雨雾、原标题与金/蓝按钮，并补齐同风格面板和方形工具底板。覆盖竖屏选角、剧情/行动、调查员、资料/案件、菜单、配置/声音、存档、骰子、恢复与结案；原生启动/窗口/导航底色同步。原应用图标、签名、加密续玩与玩家配置优先级保持，授权 MiMo 默认只在 APK 注入，Git/网页不含密钥。原稿不进入仓库，见 [[concepts/game_ui]] 与 [验收证据](../../design-qa.md)。下方旧版本说明保留为历史。

0.4.32 案件搜索/筛选复用绘制黄铜护框，清除搜索为 44px 目标，身份/关系文字 14px；手机收起重复摘要，固定控件下滚动档案，原查询/关联返回和行动保留。已知资料随基础界面提供，关闭不整理模型；APK 剔除不用的桌面图/布局和无引用生成 worker，正式包再检查。网页保留图及失败后的照片档案，原美术/音频保留，见 [[concepts/case_board]] 和 [[concepts/game_ui]]。

安卓版用独立入口与构建配置复用当前 React/TypeScript 游戏。2026-09-28 经用户确认，`codex/android-apk` 的 0.4.5 及此前改进合入 `main`，网页与 APK 共用主工程；旧网页版本保留在 Git 提交 `118cf49`。使用 Capacitor 原生 Android 容器，复用游戏规则、剧情、资料、音乐、骰子和美术，不重做 Unity 游戏逻辑。

## 运行行为

0.4.37 实时调查员档案在手机将核心资源排为两列，标签与上限 14px、当前值 22px，属性缩写 12px；队友与分类操作 15px。短键盘窗口保留队友切换与固定关闭，原查询、阅读位置和行动草稿不变。沿用已有材质，无新图片或规则，见 [[entities/character_system]] 与 [[concepts/game_ui]]。

正式回归命令 `npm run android:test` 共用交付 APK 和长期签名，指定专用设备后覆盖安装，同签名测试 runner 成功后自动清理；不再维护另一份 debug 游戏包，也无需卸载当前正式版。设备缺失/空白或混用调试参数在构建前退出，真实测试须非零且通过；失败保留旧交付和临时诊断，见 [Android 交付说明](../../docs/ANDROID.md)。此工程改进不改变当时交付 0.4.29 的游戏内容。

0.4.29 修复回合恢复的递归尺寸通知，正常/输入法窗口与多行行动适配保持稳定；原草稿、焦点、行动人和重试请求保留。浏览器和原生回归直接检查尺寸错误，无吞掉错误的处理，见 [[concepts/game_ui]]。

0.4.28 队员资源卡使用现有档案护框与清晰字号，正常窗口每位调查员均可直接查看；已提交保持可读，点开/关闭不改变原行动人或草稿。手机通常双列，760px 以上原生宽竖屏才用四列；320px 多行行动保留完整队伍边界，输入法短窗口仍收起状态条，见 [[concepts/game_ui]]。

0.4.27 保存反馈移到顶栏下方，15px 档案条完整换行，不盖住 HP/SAN 或行动、不拦截触摸。展开时短确认放右侧空位，保留 NPC 名牌；AI 设置仅确认保存，长说明四秒，离开游戏清理计时器。手机多行输入优先留出完整操作/队伍区，再让场景缩小；原短窗口收起规则、剧情阅读和草稿保持，见 [[concepts/game_ui]]。

0.4.26 原生检定/恢复条沿用绘制档案，标题 16px、说明/按钮 15px、触控至少 44px；正文完整换行，正常高度全队可查看，短窗口优先保留阅读和当前操作。掷骰/重试沿用原请求和已锁定结果，离线回归通过真实触摸核对单人恢复与四人检定，见 [[concepts/game_ui]]。

0.4.25 原生设置保存缺项直接定位对应字段、就近反馈，仅地址错误展开连接设置。手机短窗口和实际输入法占位时仅滚动字段正文，关闭/保存固定，主要文字至少 15px；取消返回保留原多行行动，未保存的修改不覆盖加密连接。沿用原 MiMo 默认、玩家连接优先级与校验要求，见 [[concepts/game_ui]]。

0.4.24 升级后的旧自动/手动记录重新绑定原调查员的过期包内图片地址，保留自定义图片、成长属性、宣言与已锁定骰点；加密续玩仍走原存储与恢复端口，不添加字段。见 [[entities/save_system]]。

0.4.24 网页与 APK 共用原尺寸/品质的 WebP 生成和同一缓存，内容/尺寸策略分键，原子写入避免半文件、损坏可重建；成功资源构建只删过时哈希条目并保留当前原图对应缓存。正式 PNG/透明边缘、音频/字体/绘制 UI 和签名资源保留，7 张无引用的暗版背景从工作区移除，历史仍可由 Git 恢复。见 [[concepts/game_ui]]。

0.4.23 收拢长篇剧情标记/人物颜色的重复计算，原生长历史检查通过加密会话端口建立 200 条四人记录，验证输入、人物查看返回、切换行动人均保留全文和阅读位置。规则、模型请求与资源不变，见 [[concepts/game_ui]]。

0.4.22 剧情名牌、展开/收起与新内容统一 44px 绘制材质，手机名字至少 14px；标题固定、正文滚动，窄屏临时折叠身份说明以保留操作。名牌仍查看已知人物，原生回归核对真实触摸与实际边界，不改资料、存档、阅读跟随或规则。见 [[concepts/game_ui]]。

0.4.21 同步修复新回复先于滚动事件处理时的回看跳转，以实际位置保持阅读，不增加模型请求或等待。

0.4.39 声音引擎在长音轨淡出结束后释放闲置解码缓存，当前场景、播放中与未淡出内容保留，淡出期间折返不重复解码，短音效复用；原曲和品质不变。已解锁声音设备恢复时，当前已开启的音乐/环境声自动继续，包括暂停期间加载的音轨；过时短音效不补播。原生回归以实际 Web Audio 暂停/恢复验证无新触摸接续，保留独立静音、后台暂停、加密偏好与 Activity 重建。声音弹窗沿用绘制档案与 44px 控件、15px 主要文字；关闭固定，长鸣谢仅内部滚动，短窗口返回正常。零音量/静音禁用试听，原配乐、响度、授权及存档不变，见 [[concepts/audio_system]] 与 [[concepts/game_ui]]。

0.4.20 结案档案可回顾公开进度、查看实时队友属性并直接返回首页；自动会话或手动结案记录以「回顾调查」继续，未配置 API 也能回看。原生存储仍走加密端口，回顾/返回不再次结算奖励或请求模型；手机两行摘要、完整进度说明、至少 44px 操作及正常窗口全部队友保留。短窗口保住回顾/返回，既有签名和存档格式不变。见 [[entities/save_system]] 与 [[concepts/game_ui]]。

0.4.19 原生调查员档案同步绘制材质、15px 技能/背景正文和 44px 操作。搜索清空后继续输入，页签保留阅读位置，换队友保留查询；输入法占位不隐藏队友切换，收紧身份和间距以保留技能正文。仍读当前角色的真实资源与检定阈值，查看不改草稿/行动；没有新增素材、存储字段或 AI 规则。见 [[entities/character_system]] 与 [[concepts/game_ui]]。

0.4.18 首页优先接续当前调查，返回首页和取消选角保留草稿、行动人、已声明行动与原骰点。当前会话先进入内存，再由既有加密端口保存；等待/失败不会改用旧会话，过时写入的完成与报错不覆盖新状态。失败仍显示真实存储提示，恢复待处理行动需主动重试，不重复结算；存储格式与签名不变。共享网页只保留当前页面内的续接，见 [[entities/save_system]] 与 [[concepts/game_ui]]。

0.4.17 进度和日志复用绘制档案，正文为 15px，当前目标优先、回顾按需展开；空统计收起，已公开局势保留原值。可搜索可见日志正文或时间，切页保留查询/位置，退出资料重置；固定操作与独立滚动兼顾 300px 键盘窗口，原生检查实际触摸清空及焦点。无新增素材或 AI/存档规则改变，见 [[concepts/game_ui]]。

0.4.16 手机顶部资料图标使用普通点击，小幅手指漂移仍能打开；桌面拖动位置在松手/取消时复位，保留键盘访问。原生验收发送实际 down/move/up 验证正式 WebView；旧手工案件画布/列表样式移除，新包校验后仍保留最近两版。见 [[concepts/game_ui]]。

0.4.15 同步共享桌面照片关系图及中文 44px 工具，修复详情展开裁卡和筛选后画布未适配，关闭恢复原视角。手机/原生宽竖屏继续档案列表且不启动图或 worker；新包复用现有美术，仍按最近两版交付收拢。见 [[concepts/case_board]]。

0.4.34 人物/地点详情使用原照片与绘制护角，身份/关系/记录标签 14px、小标题/正文/来源 15px，来源以 48px 黄铜控件展开；标题/关闭固定，已知信息单独滚动。关联资料直接查看，手机系统返回先回上一份，再回列表，保持查询/类型及行动草稿；桌面 Esc 只关侧边详情。来源默认折叠，未知秘密数量不展示。短窗口收起照片保留阅读和退出，原图片/审核/行动不变，见 [[concepts/game_ui]]。

0.4.13 在正式包签名/内容检查与校验文件完成后，自动收拢 `output/apk`，通常保留最新及上一版；校验失败不删除原包，重打旧版本保留较新包。临时对齐和增量安装文件移除。维护命令可清理完成的音频制作缓存，成品与许可不动；标题静态封面与 WebM 共用，旧源图可从 Git 历史恢复。见 [交付约定](../../docs/ANDROID.md)。

0.4.12 使用带照片的案件档案卡，页签/关闭/搜索/筛选固定，只有列表或当前正文滚动。搜索、详情返回与标签键盘交互完整，避免重复统计和剧本总数提示；原生宽竖屏也保持列表，不加载桌面关系图或布局 worker。沿用既有资料来源和反剧透边界，见 [[concepts/case_board]]。

0.4.38 与共享网页保留 24 句等待文案，每轮打乱并每 8 秒轮换，一轮内不重复；固定 15px 行高不移动剧情、完成停止、不占用掷骰随机。损坏自动会话只显示简短恢复说明，原记录和手动存档保留；单条加密内容损坏被隔离，其他有效记录可读取，原密文不删除，设备/密钥访问失败仍用原启动重试。持久化确认等待期间加入的更新和删除，并如实反馈后续失败。首页退出为绘制档案卡与黄铜操作，先等待一次保存，期间不重复退出或误关；失败在当前面板可重试/取消。四手机与 300px 短窗口确认常驻，沿用原存储格式，见 [[concepts/game_ui]] 与 [[entities/save_system]]。

0.4.35 局内合并成「读取存档」并先选择记录，关闭保留草稿，首页继续一键接续。外框、退出与确认使用既有绘制边框，日期/姓名 14px、操作/确认 15px，三/四人照片与完整姓名在手机上下排布。以调查档案卡显示本地存档，删除先确认；写入失败恢复原库缓存，后续生命周期 flush 不补做已报失败的改变。连续保存只产生一份记录，标题/关闭固定、列表内部滚动，兼顾键盘占位。沿用加密存储、v8 数据及原签名，详见 [[entities/save_system]]。

0.4.10 按用户新授权，正式 APK 在构建时读取系统 `APIKEY_MIMO`，默认使用 MiMo Token Plan / `mimo-v2.6-pro`，初次游玩无需配置；已保存的玩家连接优先，设置入口保留。真实密钥不入 Git、不进入网页构建或开发预览。MiMo 协议适配保留工具往返和私有推理，正文使用受校验的 JSON；见 [构建约定](../../docs/ANDROID.md)。闪避基础修正为敏捷一半，旧存档只迁移原错误基础，并保留既有锁定检定与玩家投入。

0.4.42 建议行动复用既有档案护边，14px/44px，提交与下一位为 15px/48px；手机建议横向滚动、窄屏收紧按钮边距，组件尺寸覆盖旧通用手机规则。行动建议按原顺序本地去重，不增加模型要求或重试；点击只填入当前调查员，仍可自由修改。手机空提示简化为「描述你的行动…」，角色身份保留在头像、队员卡和可访问名称中。手机行动支持多行输入，回车换行、按钮确认；APK 在宽竖屏也保持该行为。长行动限制输入框高度，键盘出现进一步收紧；下一位接续输入，换行及草稿通过现有加密自动续玩恢复。回看剧情时新回复不强制跳转，可点「新内容」从最新开头读取。多人卡简洁标识行动顺序，查看属性不改宣言。

0.4.40 调查菜单分组 14px、操作 15px、操作/继续为 48px 目标，固定关闭与继续、列表独立滚动。配置保持精简：非默认连接保持明确，固定关闭、保存与校验反馈；键盘占位只滚动字段，保存等待实际写入。菜单和声音按层返回。0.4.7 更新调查员档案卡及主操作材质，完整资料按需展开，选人与查看资料互相独立；手机继续单列，底部摘要/进入常驻。美术随包离线提供，沿用原 release 签名。见 [[concepts/game_ui]] 与 [控件优化](../../docs/reviews/2026-10-08-ui-polish.md)。

0.4.6 修复严格 API 格式、否定骰果误判、无需/将来检定及多人漏骰；非阻断质量诊断不额外生成，KP 笔记只留开发侧，网络错误过滤原始接口内容，检定日志明确角色与技能。保留 0.4.5 的即兴叙事、未证实猜测与单条重试通知。见 [[entities/ai_dm]] 与 [回合流畅性验收](../../docs/reviews/2026-09-28-turn-smoothness.md)。
