# 动态案件板与调查台

0.5.39 在同一次详情查阅中保留各份已知资料的阅读位置和信息来源展开状态；顺着关系查看其他记录，再使用原返回按钮或手机系统返回时接续阅读。首次查看从顶部开始，关闭详情后释放临时记录；正文、来源和关系每次仍取自当前已知事实，搜索条件与网页 Esc 关闭行为保持。复用既有银蓝精绘面板，无新增素材、控件、存档字段或模型限制。见 [[game_ui]] 与 [[android_app]]。

0.5.11 将案件地点缩略图放进 84×56px 的横向银蓝装裱，复用既有精绘阅读框作 3px 护边，原场景全幅居中 contain。手机照片档案、网页关系卡与图加载失败后的档案共用这套表现；名称、身份与关联文字保持原字级，人物照片和完整场景详情继续沿用原图。320px 窗口保留清晰文字与完整箭头，不增加卡片最小高度、素材文件或玩家操作。 见 [[game_ui]]。

0.5.10 让网页关系卡与手机照片档案保持同一字级：名称 17px、身份说明 14px、类型 13px、状态 12px，关系文字 13px。卡片布局同步为两行标题、身份与状态预留空间，ELK 与实际卡片使用同一尺寸；人物缩略图以原头像填满装裱、地点保持全幅居中，完整原图仍在详情里。沿用现有银蓝面板和透明装裱，缩放、关联返回、已知资料审核与手机单列保持，不增加素材、操作或模型限制。 当前材质以 [[game_ui]] 为准，下面的黄铜记录仅为历史行为说明。

0.4.32 案件搜索/类型使用既有黄铜材质，16px 输入、48px 类型/推测操作和 44px 清除按钮；照片卡类型/身份/关系为 13/14px。手机省去重复数量摘要，保留可访问标题、固定控件和独立资料滚动。查询/筛选/来源/关联返回沿用原逻辑。基础档案只在打开时整理模型，APK 剔除不用的桌面图；网页仍按需图及异常后的同模型照片档案，游戏不被卸载。无新增素材或公开资料；见 [[game_ui]] 与 [[android_app]]。

0.4.15 桌面关系图复用照片档案，44px 中文缩放/总览保持可达。详情打开按实际剩余画布定位当前节点/附近关系，关闭恢复原视角；过滤和尺寸变化重新适配，普通阅读保留手动镜头。当前卡不会因太多关系缩得不可读，减少动态效果时无过渡。手机仍不构建图/worker，事实与关联仍走原审核链路。

0.4.34 资料详情展示原人物/场景画面与绘制照片护角，身份/关系/记录标签 14px，小标题/正文/来源 15px；来源用 48px 黄铜折叠控件按需展开。标题和关闭保持固定，已知正文独立滚动；关联入口仅指向当前已知模型中的记录。连续查看保留搜索/类型，重复记录截断路径；手机系统返回先回上一份资料，桌面 Esc 只关详情并保留外层案件页。推测记录仍标明待验证，原审核和反剧透边界不变，无新增资料或图片。

0.4.12 移动端复用原人物/场景照片和档案底板，去掉重复计数、单记录重复标题与零项摘要；资料页签和搜索/筛选常驻，长列表单独滚动，详情返回原卡片。手机与原生宽竖屏不构建隐藏关系图，React Flow/ELK/worker 仅桌面按需加载；手机/桌面切换保留查询与类型，清除不可见的脉络筛选。进度只显示已发现/已分析数量，不泄露剧本线索总数。事实来源、可见范围和 patch 审核不变。

## 定位

案件板是玩家可见的调查工作区，不是完整日志，也不是 AI 自由生成的证据墙。v7 使用“静态主线骨架 + 确定性实体档案 + AI 核心关系提议 + reducer 审核”的混合结构。

## 信息分层

- 主图只显示人物、地点、物证、关键事件和核心推测。
- `goal`、`stance_toward`、`knowledge`、`capability`、`state` 进入所属实体的 insight 时间线。
- `relationship` 仅在双方都为玩家已知实体时成为关系边，否则进入已知主体档案。
- 新物品激活剧本静态节点，不重复创建动态物证卡。
- 事件至少连接一个可见锚点；推测至少连接两个可见锚点。

## 身份与审核

- 节点按 `semanticKey` 合并。
- insight 按 `slotKey` 更新。
- 关系按 `relationKey` 更新，并可从 hypothesis 升级为 confirmed。
- 所有动态内容必须引用玩家已见 fact、event 或 clue；未解锁 secret、未来后果和孤立节点不得进入主图。
- 上限为 30 个动态核心节点、60 条动态边和 120 条 insight，超限优先归档旧的低置信推测。

## 展示

- 桌面端由 React Flow 渲染，ELK Layered 负责从左到右分层和正交连线。
- connected components 自动形成“调查脉络”；支持搜索、类型筛选、推测开关、平移、缩放和适配。
- 选中节点后显示右侧档案，包括公开描述、已解锁信息、关系、insight 时间线和玩家可读来源。
- 移动端改为按调查脉络分组的纵向列表，并使用全屏详情层。
- 坐标不进入模型契约或存档；后台新增节点保持当前视口。

## 存档迁移

v7 存档持久化核心节点、关系和 insights。v6 存档在 hydrate 时根据原子事实确定性迁移：目标、态度和知识卡折叠进实体档案，关系卡转为边，孤立低价值卡归档。迁移不调用模型。
