# 共享交互 UI

0.5.53 后台场景或音量更新分别处理各声音通道：未变化且仍启用的循环保持暂停位置，只释放已变化、清空或关闭的通道。回到前台接续未变化的音轨，仅为变化的通道创建新音轨；后台输出保持静音，过场缓存、独立开关、设备暂停失败兜底和现有游戏UI保持。

0.5.52 切到后台先静音，再暂停当前音乐与环境声，回到前台从原位置接续。已过场的渐出声和短音效释放，后台场景/声道变更按当前配置处理；设备暂停失败时停止循环兜底，后台调整音量仍保持静音。声音设置、音量、配乐资源、精绘UI和游戏状态保持。

0.5.51 输入行动时复用未变化的完整剧情行，减轻长记录下的重复渲染。正文、关键词、人物身份、已知资料或当前末条发生变化仍刷新，点击详情使用最新已提交状态；完整历史与原阅读位置保留。沿用0.5.50精绘UI、手机单列菜单和具体游戏图标，剧情、检定、模型请求和存档规则保持。

0.5.50 用与原蓝银档案一致的精绘人物浮雕和折叠地图替换案件板线框小人/地图针；图像仅作类别符号，已有立绘与场景图保持，加载失败时仍可阅读。两张128px透明WebP合计17,362字节，原22张美术保留。手机调查菜单一行一个操作，删除重复分类标题；文字放大时四字操作不拆行，关闭/继续与独立正文滚动保持。网页沿用同套美术及原桌面两列，不增加搜索、筛选、控件、剧情规则或模型调用。短网页窗口同步收紧菜单顶部留白，避免正文被压到不足一行；移动端安全区保持。

0.5.49 将案件卡片、关联、调查记录与信息来源中的已知队员内部编号转换为真实姓名，事实主体 world 显示为「现场」。只处理阅读投影，后台引用、旧存档与未知标记保持，避免短编号误替换较长编号。完整有效的内置默认连接默认收起地址/协议，玩家自定义或不同连接仍展开，手动展开、缺项定位、密钥遮蔽和保存保持。未新增控件、美术、模型调用、提示词或游戏限制。

0.5.48 按用户要求收掉案件板搜索、类型/推测/脉络筛选，以及日志和技能搜索，连同清空按钮、无匹配提示、旧状态和样式一起删除。资料直接翻看全部已知照片档案，技能按实际数值完整排列，日志按原顺序显示玩家记录；切页、队友比较和关联返回仍接续各自阅读位置，关闭后释放。窄横向短窗口的资料标题区同步收紧。游戏图标重新绘为亨利与雾夜伦敦的具体角色画面，统一桌面、系统启动、网页和独立主题剪影；删除旧抽象圆角源图及 13 个无引用的安卓模板资源（117,133 字节）。原剧情自由度、已知事实审核、骰子/资源/存档/多行草稿和共用文字居中保持。

0.5.14 为空日志、日志搜索无匹配与空存档补齐专用银蓝调查册插画，沿用原稿银框、星珠、冷蓝布料与空白纸页。新增压缩 WebP 14,954 字节，112×72px 等比例显示，原状态文字 15px；不命中、不额外朗读。没有记录时在原日志阅读区居中，空存档沿用原区域；高度不超过 500px 时收起装饰，状态、搜索与关闭仍可到达。查询、焦点、原草稿和存档操作保持，不增加模型限制、存储字段或玩家步骤。 见 [[entities/save_system]]。

0.5.13 将选角完整属性的中文名称直接显示在精绘数值格内：力量、体质、体型、敏捷、外貌、智力、意志和教育用 13px 正文，原缩写 12px 作副标签，数值保持。手机无需依靠悬停提示辨认属性，与局内档案的称谓一致；折叠时不增加内容，展开继续在原列表滚动，选择、默认人数、固定进入和取消后原调查恢复保持。不增加属性解释弹窗、素材、存档字段或规则。 见 [[entities/character_system]]。

0.5.12 精修选角档案：职业 13px、简介 14px、擅长技能 13px，HP/MP/SAN/幸运标签 12px；核心和展开属性格复用银蓝精绘框，保留四类数值色标。展开属性标签 13px、技能和背景 14px，固定底部人数 14px、模式 13px。手机仍一行一人、独立纵向滚动，文字自然换行；整张选择与详情操作分离，默认单人、空队伍禁用、1/2/4 人与取消选角后原调查恢复保持，不增加素材、数值或游戏步骤。 见 [[entities/character_system]]。

0.5.11 将案件地点缩略图放进 84×56px 的横向银蓝装裱，复用既有精绘阅读框作 3px 护边，原场景全幅居中 contain。手机照片档案、网页关系卡与图加载失败后的档案共用这套表现；名称、身份与关联文字保持原字级，人物照片和完整场景详情继续沿用原图。320px 窗口保留清晰文字与完整箭头，不增加卡片最小高度、素材文件或玩家操作。 见 [UI_SYSTEM](../../docs/UI_SYSTEM.md)。

0.5.10 让网页关系卡与手机照片档案保持同一字级：名称 17px、身份说明 14px、类型 13px、状态 12px，关系文字 13px。卡片布局同步为两行标题、身份与状态预留空间，ELK 与实际卡片使用同一尺寸；人物缩略图以原头像填满装裱、地点保持全幅居中，完整原图仍在详情里。沿用现有银蓝面板和透明装裱，缩放、关联返回、已知资料审核与手机单列保持，不增加素材、操作或模型限制。 见 [UI_SYSTEM](../../docs/UI_SYSTEM.md)。

0.5.9 将长等待从逐字跳动改为静止字句配精绘银蓝钢笔尖：复用原稿银蓝、珠光与克制金节点，24px 装饰只有 3.6 秒明暗变化，减少动态时静止。15px 字句、36px 等待行、24 句/8 秒轮换和原朗读状态保持；等待现固定在剧情面板底部，长行动、缩窗或回看记录时仍完整可见，正文独立滚动，回复完成后释放占位，不额外增加面板高度；新 WebP 4,778 字节，原 alpha 与完整生成提示词可追溯。装饰不命中，不新增模型请求、计时器、限制或玩家操作。 见 [UI_SYSTEM](../../docs/UI_SYSTEM.md)。

0.5.8 补齐 AI 设置的连接折叠栏：复用银蓝绘制框，保持 15px 标签、44px 点击与原设置/箭头图标，悬停和按下沿用轻微亮度反馈。原生 details 的点击、回车展开与字段顺序不变，减少动态时关闭过渡；设置正文滚动、固定关闭/保存、校验与自定义连接优先保持。无新素材、字段或操作步骤。 见 [UI_SYSTEM](../../docs/UI_SYSTEM.md)。

0.5.7 补齐存档删除控件：沿用原稿浅蓝按钮、深红文字与原图标，15px 字号、至少 96×44px，按下反馈和焦点与整套控件一致。修正通用按钮覆盖危险操作文字的问题，确认删除正常及悬停均与保留区分。原就近确认、保留优先、取消回原入口、写入完成才移除、失败保留记录和原行动保持；无新增素材或步骤。 见 [UI_SYSTEM](../../docs/UI_SYSTEM.md)。

0.5.6 补齐网页案件控件美术：调查脉络复用原稿金色选中、浅蓝普通按钮，点击高度至少 44px，名称 15px、数量 13px，长名完整换行。人物照片接入透明银蓝装裱，关系图工具复用精绘托板，保留筛选、放缩、关联查看与返回位置。手机仍用已知照片档案单列，切到手机自动清除隐藏脉络筛选；原多行行动和队伍保持。 见 [UI_SYSTEM](../../docs/UI_SYSTEM.md)。

0.5.5 补齐短窗口调查员档案：网页在低高度采用与手机一致的精简档案头，关闭、队员切换、分类与搜索保持固定，技能正文独立滚动。300px 高仍能完整查看筛选后的技能和检定阈值，短窗口表头至少 13px；恢复大窗口接回原头像和身份。保留技能查询、阅读位置、队友属性和原行动，沿用精绘图，无新规则或步骤。 见 [UI_SYSTEM](../../docs/UI_SYSTEM.md)。

0.5.4 网页资料入口考虑自身高度，拖动/窗口变化不越界；桌面低高度先让出场景与建议，300px 通过头像查看全队，长输入/正文/确认保持。正常窗口恢复原场景和队员，手机竖屏固定入口保持，见 [UI_SYSTEM](../../docs/UI_SYSTEM.md)。

0.5.3 共用弹窗不抢输入法组字中的 Escape/Tab，取消候选或选择候选不会关闭未保存设置或跳走焦点。普通关闭、嵌套详情、焦点循环和返回原入口保持；游戏行动与 0.5.2 美术保留。实现见 [共用焦点逻辑](../../src/components/shared/useDialogFocus.ts)，正式验收见 [design-qa](../../design-qa.md)。

0.5.2 按原稿风格精绘七类专用资源：骰子命运面板、银蓝档案阅读框、透明立绘装裱、深色输入槽、方形工具底板、标题分隔线和珠光推子。首页原标题与金/蓝按钮保留，全部生产界面使用实际压缩图；层次和装饰集中在边缘，文字、立绘与触摸区域独立。骰子保留原骰面和字体，点数区、舞台及唯一结果签牌各有安全区，小屏/短窗口保持可读与可确认。新素材不添加文字、人物、模型限制或操作步骤。

透明立绘框不拦截头像和原 checkbox；标题线在既有留白中，不改变固定标题或滚动边界。输入、搜索、选择器复用精绘深槽，音量与开关使用圆珠图。来源、完整提示词及导出见 [资源说明](../../assets/ui/artist/README.md)，实现与验收见 [UI_SYSTEM](../../docs/UI_SYSTEM.md) 和 [design-qa](../../design-qa.md)。

从 0.5.0 起视觉以用户指定 `D:\首图素材（这版为准）` 为准，替换旧黄铜/皮革。首页原标题、金色新游戏和浅蓝继续/设置直接使用原成品，其他按钮从原 PSD 分离无字底板；配套冷蓝阅读面板和方形工具底板补齐缺失界面。手机竖屏优先，选角、主剧情、行动、属性/技能/背景、资料/案件、菜单、AI/声音、存档、恢复、骰子和结案采用同一规范。来源与切片见 [原稿资源](../../assets/ui/artist/README.md)，实际对照见 [design-qa](../../design-qa.md)。以下旧版本段落保留行为历史，视觉以本段及 UI_SYSTEM 为准。

默认单人、一行一卡、多行草稿、头像属性、固定任务/展开上限、读档先选记录和首页一键接续保持。有调查时继续获得焦点，但导航顺序按原稿。窄四人加长输入仍保留全部队员入口与至少 140px 剧情；键盘短窗口优先保留阅读/提交。原百分骰、字魂云雀宋、场景/人物/图标和声音不变；视觉重构不新增模型调用、提示词限制或存档字段。旧控件与古铜面板在完全替换后收拢，仍被介绍页引用的历史场景保留。对应 [[concepts/android_app]]。

0.4.32 案件搜索/类型控件复用绘制黄铜边，输入 16px、推测操作 15px，清除有 44px 目标；卡片身份/关系 14px、类型 13px，手机移除重复数量摘要。控件保持固定、资料正文滚动，清空继续输入、关联和关闭返回保留原查询/焦点/草稿/队伍。组件统一控件样式并移除旧分散覆盖，无新素材或操作；网页图及 APK 文件收拢沿用原约定，见 [[concepts/case_board]]。

0.4.29 输入区恢复和尺寸变化时，将观察回调中的换行宽度调整合并到下一帧，修复递归尺寸错误；打字/窗口高度仍即时适配，旧回调随离开/换行动人取消。原草稿、焦点、高度上限和回合顺序保持，见 [[concepts/android_app]]。

0.4.28 队员卡复用绘制档案护框，姓名 14px、数值 13px、标签/行动状态 12px，至少 44px 点击；已提交不淡化整张卡，原实时属性入口、行动人与草稿保留。HP/SAN 标签/数字整体排布，手机多人双列，原生宽竖屏到 760px 才用四列，短窗口沿用收起规则，见 [[concepts/android_app]]。

0.4.27 保存等反馈位于顶栏下方，15px 绘制档案不盖住底部数值/行动、不抢触摸或焦点，展开时短确认留出 NPC 名牌；长说明四秒，AI 设置简短确认保存，稳定读屏区域与计时器清理。手机操作区按完整内容分配高度，场景先让出空间；桌面共用结案已验证的网格，修复多行输入挤掉队员。原草稿、队伍、展开阅读和骰点保留，见 [[concepts/android_app]]。

0.4.26 当前检定/恢复条使用统一绘制档案、16px 标题及 15px 说明/按钮，操作至少 44px，文字完整换行。正常手机窗口保留全队卡和至少 140px 剧情，短窗口按钮可命中；桌面也收起该阶段的禁用输入行，结束后恢复原输入。原回合、宣言、检定队列和内部信息隔离保留，见 [[concepts/android_app]]。

0.4.25 AI 设置缺项就近说明并直接定位输入，标签/提示/底部操作至少 15px，输入 16px、触控 44px。仅地址出错展开连接设置，字段区随输入法占位保持当前输入可见，外框/关闭/保存固定；编辑清除旧反馈，保存失败保留已填内容，返回原行动。连接约定与授权默认值不变，见 [[concepts/android_app]]。

0.4.24 旧记录恢复后使用当前调查员立绘，包内图片文件名变化不会让头像与档案缺图；自定义图片、原属性和多行行动保留。见 [[entities/save_system]]。

0.4.22 剧情顶部三个入口统一为 44px 档案/黄铜控件，已知 NPC 名字至少 14px，窄屏新内容出现时只折叠身份说明。名牌保留原资料入口、完整可访问名称，关闭后继续原处阅读；不加工具排，不改阅读跟随和行动，删除旧分散尺寸规则，无新素材。见 [[concepts/android_app]]。
