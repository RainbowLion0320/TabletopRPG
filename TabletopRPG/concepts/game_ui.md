# 共享交互 UI

0.4.32 案件搜索/类型控件复用绘制黄铜边，输入 16px、推测操作 15px，清除有 44px 目标；卡片身份/关系 14px、类型 13px，手机移除重复数量摘要。控件保持固定、资料正文滚动，清空继续输入、关联和关闭返回保留原查询/焦点/草稿/队伍。组件统一控件样式并移除旧分散覆盖，无新素材或操作；网页图及 APK 文件收拢沿用原约定，见 [[concepts/case_board]]。

0.4.29 输入区恢复和尺寸变化时，将观察回调中的换行宽度调整合并到下一帧，修复递归尺寸错误；打字/窗口高度仍即时适配，旧回调随离开/换行动人取消。原草稿、焦点、高度上限和回合顺序保持，见 [[concepts/android_app]]。

0.4.28 队员卡复用绘制档案护框，姓名 14px、数值 13px、标签/行动状态 12px，至少 44px 点击；已提交不淡化整张卡，原实时属性入口、行动人与草稿保留。HP/SAN 标签/数字整体排布，手机多人双列，原生宽竖屏到 760px 才用四列，短窗口沿用收起规则，见 [[concepts/android_app]]。

0.4.27 保存等反馈位于顶栏下方，15px 绘制档案不盖住底部数值/行动、不抢触摸或焦点，展开时短确认留出 NPC 名牌；长说明四秒，AI 设置简短确认保存，稳定读屏区域与计时器清理。手机操作区按完整内容分配高度，场景先让出空间；桌面共用结案已验证的网格，修复多行输入挤掉队员。原草稿、队伍、展开阅读和骰点保留，见 [[concepts/android_app]]。

0.4.26 当前检定/恢复条使用统一绘制档案、16px 标题及 15px 说明/按钮，操作至少 44px，文字完整换行。正常手机窗口保留全队卡和至少 140px 剧情，短窗口按钮可命中；桌面也收起该阶段的禁用输入行，结束后恢复原输入。原回合、宣言、检定队列和内部信息隔离保留，见 [[concepts/android_app]]。

0.4.25 AI 设置缺项就近说明并直接定位输入，标签/提示/底部操作至少 15px，输入 16px、触控 44px。仅地址出错展开连接设置，字段区随输入法占位保持当前输入可见，外框/关闭/保存固定；编辑清除旧反馈，保存失败保留已填内容，返回原行动。连接约定与授权默认值不变，见 [[concepts/android_app]]。

0.4.24 旧记录恢复后使用当前调查员立绘，包内图片文件名变化不会让头像与档案缺图；自定义图片、原属性和多行行动保留。见 [[entities/save_system]]。

0.4.24 新版网页复用 APK 的场景/人物 WebP 策略，保持全幅和透明度，原图继续用于美术迭代。共用生成缓存并按当前原图保留，移除无引用的暗版背景；材质、字号、布局、颜色与阴影不变，无新玩家控件。见 [[concepts/android_app]]。

0.4.23 每次剧情渲染共用已知术语/人物颜色，逐条正文的 AI 提示独立；下一次渲染重读完整状态，不以对象身份或部分字段缓存知识。减少长历史输入时的重复扫描，保留全部正文、标记/颜色、详情回调和回看位置，无新增资源、UI 或跑团约束。见 [[concepts/android_app]]。

0.4.22 剧情顶部三个入口统一为 44px 档案/黄铜控件，已知 NPC 名字至少 14px，窄屏新内容出现时只折叠身份说明。名牌保留原资料入口、完整可访问名称，关闭后继续原处阅读；不加工具排，不改阅读跟随和行动，删除旧分散尺寸规则，无新素材。见 [[concepts/android_app]]。

0.4.21 另修复剧情跟随的滚动事件竞态：新回复以实际阅读位置和此前最新记录起点判断是否跟随，尚未处理的 scroll 事件也不会让回看跳走；保留主动「新内容」入口与载入替代历史行为。

0.4.21 声音设置使用既有绘制档案、黄铜开关和推子，主要文字 15px、触控目标至少 44px。标题/关闭固定，渠道与按需鸣谢独立滚动，外框不跟随焦点移动；短窗口保留关闭，返回原菜单不丢行动草稿。保留实时音量、独立静音记忆及完整授权，无新增素材；移除旧分散的小字/小目标规则。见 [[concepts/audio_system]] 与 [[concepts/android_app]]。

0.4.20 结案面板复用既有档案底板，原结局/队伍属性保留，回顾直达公开进度，关闭返回实际入口；普通资料仍打开案件板。手机摘要限两行，完整原文在进度页，布局优先保住至少 140px 剧情与 44px 操作、正常高度全部队友；短窗口收起摘要/队伍条。首页已结案记录明确使用「回顾调查」，不再触发 AI 或结算。没有新增图片、剧情和存储字段，见 [[entities/save_system]] 与 [[concepts/android_app]]。

0.4.19 局内调查员档案复用绘制底板、照片护框、属性格和黄铜页签/队友控件，技能/背景正文 15px，操作至少 44px。清空搜索保留输入焦点，切页返回原阅读位置；换队友保留查询并从新记录开头读。短键盘窗口仍保留横向队友切换，标题/关闭/搜索固定，正文独立滚动，无新增图片。见 [[entities/character_system]] 与 [[concepts/android_app]]。

0.4.18 首页有当前调查时优先显示实心黄铜「继续游戏」，简短档案列地点、完整队伍与公开故事时间；手机限宽、短窗口精简时间。返回首页与取消选角保留当前调查，焦点自然回主操作，实际进入新调查才替换。复用既有底板并移除旧提示样式，无新增素材，见 [[entities/save_system]] 与 [[concepts/android_app]]。

0.4.17 进度/日志使用现有档案底板及 15px 正文；当前目标优先，回顾按需展开，零线索统计收起，局势保留已公开剧本标签和值。日志搜索正文/时间，切页保留查询与阅读位置，清空保持焦点，退出资料重置；标题/关闭/搜索固定，内部正文滚动。旧小字/普通卡样式移除，无新素材，见 [[concepts/android_app]]。

0.4.16 手机资料入口按固定按钮处理，轻微触屏滑动不再吞掉打开操作；桌面仍可调整入口位置，松手/取消/切换手机版式均复位，键盘保持可用。移除已停用的旧案件画布/列表控件样式，无新增素材，资料及草稿不变。见 [[concepts/android_app]]。

0.4.15 共享桌面关系图与手机档案统一照片/底板风格，中文缩放和总览为 44px 工具。当前资料在实际画布内完整显示，关闭详情恢复原视角；过滤/尺寸变化适配新内容，普通阅读不抢手动镜头。去掉重复推测标签，减少动态效果时关闭镜头过渡；样式集中在组件并删除旧覆盖，无新增素材。手机列表保留原体验，见 [[concepts/case_board]]。

0.4.34 详情复用绘制档案及原人物/场景，照片沿用现有护角；身份/关系/记录标签 14px，小标题/正文/来源 15px。来源通过 48px 黄铜折叠控件按需展开，装饰箭头标明状态；标题/关闭常驻，正文独立滚动。关联资料可连续查看与返回，不重置筛选或行动，未知秘密数量不展示。手机返回沿关联记录逐份退出，桌面 Esc 只关详情，Tab 留在整个资料页。短窗口收起照片保留退出，原图片与规则不变，无新增素材，见 [[concepts/case_board]]。

0.4.13 标题页在视频开始前或暂停时显示同画面的轻量静态封面，介绍页也用当前 WebM、封面与正式场景 PNG。移除已被替代的 GIF/占位 SVG，保留现有美术表现；原件仍可从 Git 历史找回。

0.4.12 手机案件资料使用照片档案卡，复用原 NPC/场景和底板，简洁显示身份与关系。固定页签/搜索/筛选、正文单独滚动；清空搜索和详情返回保持焦点。去掉重复统计、零计数及未发现线索总数，支持键盘标签切换。手机与原生宽竖屏不再构建隐藏画布或 worker，桌面关系图按需加载；保留原 reducer 审核链路，见 [[concepts/case_board]]。

0.4.35 经用户确认，局内只保留「读取存档」，先选择记录再载入；取消保留当前行动，首页仍一键续玩。外框、关闭和确认复用绘制档案/黄铜边框，时间/队伍姓名 14px、操作/确认 15px；手机三/四人照片与完整姓名上下排布。存档以档案卡呈现，照片、场景、时间与载入操作有独立空间；固定标题/关闭，长列表只在内部滚动。删除先在当前记录内确认，默认焦点为保留；键盘缩小窗口仍能触达操作，取消/删除后恢复焦点。不兼容记录保留，内部原因只供诊断。详见 [[entities/save_system]]。

0.4.10 在档案切换队友时保留当前技能搜索，便于对比同一技能；关闭再打开重置查询。显示修正后的闪避及三档阈值，旧锁定检定沿用原值。正式 APK 首次游玩使用已授权的默认 MiMo，无强制配置弹窗；玩家自定义连接仍优先，设置中密钥默认遮蔽。

0.4.9 支持手机多行行动与回车换行，按钮确认；桌面保留回车确认/Shift+Enter 换行。输入按内容适度增高并限制总高，下一位保持输入焦点；多人当前及已提交行动以简洁标记区分。回看旧剧情保留位置，只在有新可见内容时显示临时入口，点击从最新回复开头读取；隐藏诊断不干扰阅读。草稿换行沿用原存档。

0.4.8 菜单按调查记录、设置与导航分组，固定关闭和继续调查，声音/菜单逐层返回并恢复焦点。配置默认只显示服务商、密钥与模型；官方连接折叠，非默认连接自动展开。新表单不提前报错，密钥核对后重开恢复遮蔽；键盘占位仅滚动字段，反馈/标题/保存固定，异步保存避免重复提交、继续编辑或退出。组件分别管理菜单和配置布局，复用黄铜护角，不改协议或游戏内容。

0.4.7 用独立绘制的档案底板重排调查员卡，突出身份、两项擅长技能与核心数值；完整属性、技能和背景在列表内展开。原生勾选与详情操作独立，手机单列、网页宽屏双列，两端底部操作常驻。主要按钮改为实心黄铜与深墨文字，通用样式不再覆盖主操作颜色。选角布局收拢到组件样式，见 [本轮优化](../../docs/reviews/2026-10-08-ui-polish.md) 与 [[entities/character_system]]。

0.4.0 延续骰子美术与 1920 年伦敦调查故事，采用旧黄铜铭牌、深色皮革、档案标签与字魂云雀宋标题。统一主次按钮、图标、表单、选角标记、页签、菜单、弹窗、开关和音量推子。正文保持清晰，场景与 NPC 使用原有素材。

手机优先：主输入/提交 44px、首页主要操作 52px、菜单 48px，建议和展开等紧凑操作 40px。选角列表滚动、底部操作常驻；游戏保留上方完整场景、中部剧情和底部操作。活动、聚焦、按下和禁用都有明确反馈，图标保留可访问名称。

`game-ui.css` 管主题，`portrait.css` 管共享布局。APK 总是启用 `portrait-ui`，网页不超过 700 CSS px 时启用相同布局，切换尺寸保留角色和输入草稿。宽网页采用独立顶栏和 NPC 区。2026-09-28 经用户确认，共享 UI 及 Android 0.4.5 合入 `main`；旧网页版本保留在 Git 提交 `118cf49`。

规范见 [UI_SYSTEM.md](../../docs/UI_SYSTEM.md)，新增运行时材质、生成提示和转换步骤见 [UI 资源](../../assets/ui/chrome/README.md)，验证见 [0.4.0 检查记录](../../docs/reviews/2026-09-09-ui-system.md)。客户端与音频机制见 [[concepts/android_app]]、[[concepts/audio_system]]。

0.4.1 加入美术提供的应用图标，覆盖安卓桌面、启动页、网页标签及手机快捷图标，保持源图配色和形状；见 [图标说明](../../assets/ui/app-icon/README.md)。

0.4.2 展开故事仅占据顶栏与底部操作之间的空间，正文在 NPC 信息条下方独立滚动；NPC 名牌及收起按钮不随历史消息移动。APK 和新版网页共享修复，见 [展开阅读验收](../../docs/reviews/2026-09-09-expanded-reading.md)。

0.4.3 头像和队员卡增加点击、按下与焦点反馈，打开三页调查员档案：属性、技能、随身与背景。面板用小立绘和黄铜格保持紧凑，顶部关闭与分类常驻，正文独立滚动；多人查看不切换行动角色。实时数值来自游戏状态，技能计算复用规则函数。见 [[entities/character_system]] 与 [档案验收](../../docs/reviews/2026-09-09-investigator-sheet.md)。
