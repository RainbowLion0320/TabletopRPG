# 角色系统

## 概述

0.5.25 选角核心数值统一为生命、魔力、理智、幸运，标签为 13px，前三项原缩写保留为悬停提示；局内属性页统一为「魔力 MP」。 缩窗关闭资料面板时，原入口不可见则回到可见头像；结案后缩窗关闭人物档案回到调查回顾，普通窗口仍回原入口。原精绘数值格、四类色标、计算数值、默认单人、多人选择、档案展开、固定进入/返回与取消选角后原调查/草稿恢复保持。继续复用十五张采用图，不增加素材、玩家步骤、属性、存储或规则。 见 [[concepts/game_ui]]。

0.5.13 将选角完整属性的中文名称直接显示在精绘数值格内：力量、体质、体型、敏捷、外貌、智力、意志和教育用 13px 正文，原缩写 12px 作副标签，数值保持。手机无需依靠悬停提示辨认属性，与局内档案的称谓一致；折叠时不增加内容，展开继续在原列表滚动，选择、默认人数、固定进入和取消后原调查恢复保持。不增加属性解释弹窗、素材、存档字段或规则。 见 [[concepts/game_ui]]。

0.5.12 精修选角档案：职业 13px、简介 14px、擅长技能 13px，HP/MP/SAN/幸运标签 12px；核心和展开属性格复用银蓝精绘框，保留四类数值色标。展开属性标签 13px、技能和背景 14px，固定底部人数 14px、模式 13px。手机仍一行一人、独立纵向滚动，文字自然换行；整张选择与详情操作分离，默认单人、空队伍禁用、1/2/4 人与取消选角后原调查恢复保持，不增加素材、数值或游戏步骤。 见 [[concepts/game_ui]]。

0.4.37 局内属性/技能/背景档案复用现有绘制材质，手机核心资源改为两列，标签与上限 14px、当前值 22px；基础属性缩写 12px、队友/分类文字 15px，背景与技能正文 15px，队友/清空至少 44px。清空技能查询后回列表开头并保持输入焦点；同次查看切页保留阅读位置，切队友保留查询、从新资料开头显示。短键盘窗口仍可切队友，关闭返回原入口，实时角色资料与当前行动不变。见 [[concepts/game_ui]]。

0.4.10 修正闪避基础为 `floor(DEX / 2)`，COC 百分制敏捷不再乘二。四个预设当前闪避分别为 30、35、32、50；巡警保留原设定的技能投入。旧存档只迁移匹配原错误基础的记录，额外投入、自定义数值和已锁定检定保留；后续检定使用修正后的数值。技能搜索在队友间连续查看时保留，关闭档案后重开恢复空查询。

当前实现是“预设调查员选择”而不是自定义角色创建器。玩家可在开始游戏前从 4 个预设调查员中选择 1-4 名进入同一局游戏。0.4.7 的档案卡优先展示立绘、身份/性别/年龄/家乡、两项擅长技能与 HP/MP/SAN/幸运；完整属性、技能和背景按需展开。原生 checkbox 负责选择，详情按钮独立；空格切换选择不会触发详情，两端底部摘要与进入常驻。见 [控件优化](../../docs/reviews/2026-10-08-ui-polish.md)。

## 当前角色选择流程

0.4.4 的手机/平板竖屏选角固定一行一名调查员，600px 前后不再切换双列。立绘在左、资料在右，列表纵向滚动，底部常驻已选人数与进入按钮；展开属性不会改变选中队伍。宽设备使用居中 720px 上限，参见 [[concepts/android_app]]。

| 步骤 | 内容 |
|------|------|
| 1 | 标题页点击“开始游戏” |
| 2 | 进入“选择调查员”页面 |
| 3 | 面向单人游玩，默认只选中亨利 1 人；可替换或增减选择，总计 1-4 名，空队伍无法开局 |
| 4 | 点击“进入游戏”，初始化 `GameState` |

单人输入后直接“提交”，多人逐人“下一位”后统一结算。浏览器回归分别覆盖单人、双人和四人的行动、检定续写与存档恢复，多人测试显式添加角色。

## 属性体系

角色数据保留 COC 风格基础属性：

| 属性 | 英文 |
|------|------|
| 力量 | STR |
| 体质 | CON |
| 体型 | SIZ |
| 敏捷 | DEX |
| 外貌 | APP |
| 智力 | INT |
| 意志 | POW |
| 教育 | EDU |
| 幸运 | Luck |

派生属性：

当前派生属性由 `src/data/gameRules.ts` 的 `deriveInvestigatorStats(attrs)` 统一计算，选角 UI、预设角色生成和存档恢复不得重复写公式。

| 属性 | 计算公式 |
|------|----------|
| HP | `floor((CON + SIZ) / 10)` |
| MP | `floor(POW / 5)` |
| SAN | `POW` |

## 技能系统

当前 `src/data/skills.ts` 定义 24 个技能，分为观察、社交、知识、战斗、行动、特殊 6 类。技能值结构为：

```ts
{
  base: number,
  added: number,
  isJob?: boolean
}
```

普通技能总值 = `base + added`；幸运检定读取当前 `player.luck`，理智检定读取 `currentSan`。档案技能值与检定阈值复用 `getSkillTotal` / `getDifficultyThreshold`，不另写 UI 公式。

`equipment` 保存角色明确携带的装备。武器行动必须同时满足“装备清单中有对应武器”和“角色具备对应技能”；职业名称不隐式赋予武器。

```ts
interface Investigator {
  id: string;
  name: string;
  portrait?: string;
  gender: string;
  age: number;
  hometown: string;
  job: string;
  role?: string;
  attrs: Attributes;
  hp: number;
  mp: number;
  san: number;
  luck: number;
  currentHp: number;
  currentMp: number;
  currentSan: number;
  skills: Record<string, SkillValue>;
  equipment?: string[];
  background?: {
    importantPerson?: string;
    belief?: string;
    meaningfulItem?: string;
    trait?: string;
    story?: string;
  };
}
```
